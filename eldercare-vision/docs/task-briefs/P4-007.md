# P4-007 — Calibrate Thresholds on Development Set Only: Task Brief

## 1. Objective
Calibrate temporal, geometric, and confidence scoring thresholds for the Temporal Fall Engine exclusively on development partition sequences (URFD dev sequences, UP-Fall dev subjects, local dev clips) per `TASK_SKILL_MATRIX.md`, `AI_SPEC.md` §8 & §9, `DATASET_PLAN.md` §7, and `ACCEPTANCE_CRITERIA.md`.

## 2. Requirements & Specifications
- **Strict Development Partition Isolation (`DATASET_PLAN.md` §7)**:
  - Threshold tuning and calibration must run ONLY on `split == "dev"`.
  - Zero test partition leakage: Any evaluation of `split == "test"` during calibration is strictly forbidden.
- **Configurable Fall Engine & Confidence Parameters (`AI_SPEC.md` §8 & §9)**:
  - Populate `config/fall_detection.yaml` with calibrated parameters:
    - Feature extraction window: `0.5s`
    - Descent velocity threshold: `0.5` heights/s, peak threshold: `1.0` heights/s
    - Low posture aspect ratio: `<= 1.0`, torso angle: `<= 40.0 deg`
    - Down confirmation duration: `1.0s`
    - Recovery thresholds: aspect ratio `>= 1.4`, torso angle `>= 50.0 deg`
    - Confidence weights: motion `0.35`, posture `0.35`, persistence `0.30`
    - Penalties: missing keypoint `0.20`, unstable track `0.15`
    - Minimum confirmation score: `0.40`
    - Alert cooldowns: track `5.0s`, camera `0.5s`
- **Config Loader & Development Evaluator**:
  - Implement YAML configuration loader mapping to `FallStateMachineConfig`, `FallConfidenceConfig`, and `CooldownConfig`.
  - Implement a calibration evaluator that validates dev-split performance and generates calibration metrics.
- **Performance Targets on Development Split**:
  - Precision >= 0.85 (target >= 0.90)
  - Recall >= 0.90
  - F1 Score >= 0.90
  - 100% rejection of standard ADLs (standing, walking, normal sitting, bending, slow lying down)

## 3. Implementation Targets
- `config/fall_detection.yaml`: Populated and calibrated configuration file.
- `src/eldercare/fall_engine/calibration/config_loader.py`: Config parser and validation with fail-closed error handling.
- `src/eldercare/fall_engine/calibration/evaluator.py`: Development set calibration evaluator with anti-leakage checks.
- `src/eldercare/fall_engine/calibration/__init__.py`: Package exports.
- `src/eldercare/fall_engine/__init__.py`: Re-exports for calibration API.

## 4. Verification Plan
- Unit tests: Config loader parsing, schema type validation, parameter range checks, anti-leakage guard (throws error if test-split sequence is supplied for calibration).
- Integration tests: End-to-end dev set calibration runner evaluating simulated URFD dev falls vs. ADLs, verifying precision, recall, and F1 meet acceptance criteria.
- Ruff linter & formatter.

# P4-005 — Dataset Manifests & Evaluation Runner: Task Brief

## 1. Objective
Implement dataset manifest schemas, CSV manifests for URFD, UP-Fall, and local clips, and a deterministic sequence evaluation runner according to `DATASET_PLAN.md`, `AI_SPEC.md` §11, and `ACCEPTANCE_CRITERIA.md`.

## 2. Requirements & Specifications
- **Manifest Schemas (`DATASET_PLAN.md` §6)**:
  - Manifests stored in `datasets/manifests/`:
    - `urfd_manifest.csv` (70 sequences: 30 falls, 40 ADLs; strict sequence-level dev/test split)
    - `upfall_manifest.csv` (17 subjects: subject-disjoint dev/test split)
    - `local_manifest.csv` (controlled local validation clips)
  - Schema columns: `sample_id`, `source_dataset`, `sequence_id`, `subject_id`, `camera_id`, `activity`, `is_fall`, `fall_type`, `path_local`, `split`, `license`, `notes`.
- **Leakage Controls (`DATASET_PLAN.md` §7)**:
  - Sequence IDs are strictly disjoint between `dev` and `test`.
  - Manifest parser enforces non-overlapping sequence validation on load.
- **Evaluation Runner & Metrics**:
  - Sequence-level evaluation computing TP, FP, TN, FN, Precision, Recall, F1, Accuracy, and Time-to-Alert.
  - Generates structured confusion matrix and reproducible summary metrics without framework dependencies.

## 3. Implementation Targets
- `datasets/manifests/urfd_manifest.csv`
- `datasets/manifests/upfall_manifest.csv`
- `datasets/manifests/local_manifest.csv`
- `src/eldercare/fall_engine/evaluation/manifest.py` (`SequenceManifestRecord`, `load_manifest`, `validate_manifest_integrity`)
- `src/eldercare/fall_engine/evaluation/metrics.py` (`EvaluationMetrics`, `compute_metrics`)
- `src/eldercare/fall_engine/evaluation/runner.py` (`SequenceEvaluationRunner`, `SequenceEvalResult`)
- `src/eldercare/fall_engine/evaluation/__init__.py`
- Re-exports in `src/eldercare/fall_engine/__init__.py`

## 4. Verification Plan
- Unit tests: Manifest schema validation, sequence disjointness verification, metrics math (precision, recall, f1, edge cases with 0 denominator), runner evaluation on synthetic sequences.
- Integration tests: End-to-end evaluation runs on dev and test split sequences.
- Linter & AST checks.

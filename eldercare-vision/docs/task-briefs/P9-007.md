# P9-007 — Task Brief: Benchmark Integrity Review & Phase 9 Closure Gate

## Objective
Execute an independent, adversarial benchmark integrity audit and comprehensive review gate across all Phase 9 tasks (P9-001 through P9-006) to ensure scientific validity, measurement reproducibility, cryptographic artifact integrity, and strict adherence to project constraints before closing Phase 9.

## Scope
- Audit all raw JSON benchmark artifacts (`p9_001_baseline.json`, `p9_002_pytorch_baseline.json`, `p9_003_onnx.json`, `p9_004_tensorrt_fp16.json`).
- Verify workload invariance: identical input resolution (640x480), identical frame count (300 measured + 40 warmup × 3 reps = 900 measured frames), identical seed (42), and identical inference sizing (imgsz=640).
- Verify measurement rigor: CUDA synchronization (`torch.cuda.synchronize()`), warmup exclusion, full-distribution percentiles, and run-to-run CV stability.
- Verify artifact provenance: trace `yolo26s-pose.pt` -> `yolo26s-pose.onnx` -> `yolo26s-pose.engine`.
- Audit all codebase and test modifications to confirm no assertion dilution or regression masking.
- Verify frozen configs and dataset manifests match ADR-005 hashes.
- Run complete test suite and linters (`pytest`, `ruff check .`, `ruff format --check .`).

## Requirements & Constraints
- Must evaluate without bias or assumptions.
- Must verify 0 unresolved Critical and 0 unresolved Important findings.
- Zero model training, zero weight modifications, zero threshold tuning, zero Phase 10 work.

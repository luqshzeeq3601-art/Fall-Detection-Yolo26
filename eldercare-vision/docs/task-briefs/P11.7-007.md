# P11.7-007 — Task Brief: Annotation & QA Verification

## Objective
Perform comprehensive quality assurance and verification across annotations for all 70 ingested real-world video sequences in the master manifest (`datasets/manifests/v4_multi_source_manifest.json`). Verify temporal boundary consistency (fall onset, kinetic descent impact, and post-fall lying intervals) against physical plausibility criteria ($0.2\text{s} \le \text{fall duration} \le 3.5\text{s}$, post-fall lying $\ge 0.1\text{s}$); audit 17-keypoint bounding box and anatomical geometry (COCO standard, non-degenerate aspect ratios, torso length, and spatial containment); execute sampling pose verification with `yolo26s-pose`; and publish audit findings in `docs/reports/P11.7-007-annotation-qa-report.md`.

## Scope
1. **QA Verification Engine (`src/eldercare/fall_engine/dataset/qa.py`):**
   - `AnnotationQAVerifier`: Evaluates temporal boundary validity, fall duration physiology, lying duration, bounding box geometry, and 17-keypoint anatomical consistency.
   - `TemporalIntervalAudit` & `PoseGeometryAudit`: Data models capturing structured defect findings.
   - `DatasetQAAuditResult`: Comprehensive audit summary across all dataset partitions.
2. **QA Audit Runner (`scripts/dataset/verify_annotations_qa.py`):**
   - Command-line runner auditing all 70 sequences in the master manifest.
   - Performs live pose model keypoint quality sampling across fall and ADL sequences.
   - Compiles `docs/reports/P11.7-007-annotation-qa-report.md`.
3. **Unit Test Suite (`tests/unit/test_v4_annotation_qa.py`):**
   - Verifies temporal interval validation on valid and defective records.
   - Verifies pose geometry audit on valid, out-of-bounds, and collapsed torso poses.
   - Verifies complete manifest audit on `datasets/manifests/v4_multi_source_manifest.json`.
4. **Independent Quality Review:**
   - Formal review gate documenting zero Critical / Important defects in `docs/reviews/P11.7-007-review.md`.

## Acceptance Criteria
1. 100% of the 30 fall sequences pass temporal validity checks ($1 \le \text{fall\_start} \le \text{fall\_end} \le \text{lying\_start} \le \text{frame\_count}$).
2. 100% of the 40 ADL sequences are confirmed to have zero fall frames or fall intervals.
3. Bounding box and 17-keypoint geometry validation confirms torso integrity, positive dimensions, and non-degenerate aspect ratios.
4. Sampling pose verification across real videos achieves average keypoint confidence $\ge 0.60$ and keypoint presence $\ge 12/17$.
5. Comprehensive audit report published at `docs/reports/P11.7-007-annotation-qa-report.md`.
6. Zero regression to quarantined artifacts (`tests/unit/test_evidence_quarantine.py` passes 100%).
7. All code passes `ruff check` and unit tests pass.
8. Independent review approval with 0 Critical / 0 Important findings.

# P11.5-003 — Task Brief: Development Set Training, Calibration & Candidate Selection

## Objective
Train and calibrate candidate fall engine configurations strictly on the development partitions of the URFD and UP-Fall datasets (69 total sequences: 31 Falls, 38 ADLs), comparing Candidate 1 (Baseline V1), Candidate 2 (V2 Rules Only), and Candidate 3 (Hybrid V2 + Learned Temporal Classifier), and selecting the winning candidate based on development split metrics without touching the test split.

## Scope
1. **Dataset Partitions**:
   - URFD Development split: 42 sequences (`dev` split, 18 Falls, 24 ADLs).
   - UP-Fall Development split: 27 sequences (`dev` split, `Subject01`..`05`, 13 Falls, 14 ADLs).
   - Anti-leakage enforcement: Zero access to 28 URFD test sequences or 15 UP-Fall test sequences.
2. **Candidates Evaluated**:
   - Candidate 1: Baseline V1 State Machine (`FallStateMachineConfig`).
   - Candidate 2: Enhanced V2 State Machine without Classifier (`FallStateMachineConfigV2`, rules only).
   - Candidate 3: Hybrid V2 Fall Engine with Learned Temporal Classifier (`LearnedTemporalFallClassifier`).
3. **Selection Criteria**:
   - Highest development F1 score, improved recall, and reduced false alerts/hour.
4. **Deliverables**:
   - `docs/reports/P11.5-003-development-calibration.json`
   - `docs/reports/P11.5-003-development-calibration-report.md`
   - `models/temporal_fall_classifier_v2.json`
   - `docs/task-briefs/P11.5-003.md`
   - `docs/task-reports/P11.5-003.md`
   - `docs/reviews/P11.5-003-review.md`

# P0-007 — CI baseline

## Purpose
Add a GitHub Actions CI workflow that enforces the Phase 0 quality gates on every push/PR: Python (install, Ruff, format-check, pytest) and frontend (npm ci, typecheck, lint, test, build). CPU-only, secret-free, daemon-free.

## Requirements
- New file `.github/workflows/ci.yml` ONLY (no other CI files; no Dockerfiles touched):
  - Triggers: `push` + `pull_request` with NO branch-name filter (local default branch is `master`; do not assume `main` — document this choice in a comment).
  - `permissions: contents: read` at top level (minimal).
  - `concurrency` cancel-in-progress for PR runs (standard `group: ${{ github.workflow }}-${{ github.ref }}`).
  - Job `python` (`runs-on: ubuntu-latest`): checkout → `setup-python` 3.10 (match local 3.10.11 major; record reason) with pip cache → `pip install -e .` → pinned tool install (`pip install "ruff==<local>" "pytest==<local>"` — bare runners have no dev dependencies declared, so gates need their tools installed; exact pins, recorded versions) → `ruff check .` → `ruff format --check .` → `pytest -v`. Pin every action to a FULL semver tag (e.g. `v4.2.2`-style, never a floating major like `@v4`).
  - Job `frontend` (`runs-on: ubuntu-latest`, `defaults.run.working-directory: frontend`): checkout → `setup-node` 24 (match local v24.14.1 major; record reason) with npm cache → `npm ci` → `npm run typecheck` → `npm run lint` → `npm test -- --run` (only if the bare `npm test` is non-watch by default — verify against `frontend/package.json`; do NOT change the script, adapt the CI invocation) → `npm run build`.
  - No services, no Docker, no GPU labels, no datasets, no secrets/env credentials, no `continue-on-error`, no `|| true`, no publishing/deploy steps.
- Failure-fails proof (honest, local): demonstrate exit-code propagation with a forced failure OUTSIDE the repo (e.g. copy one test to a /tmp scratch dir with a deliberately false assertion and run `pytest` there showing exit ≠ 0; plus `ruff check` on a scratch file with an unused import showing exit ≠ 0). Record commands + exit codes in the report. Do NOT commit scratch files; do NOT break the real tree even transiently.
- Validation of the workflow file itself: parses as YAML (`python -c yaml.safe_load`), grep proves no `continue-on-error` / `|| true` / `secrets\.` / `docker` / `gpu` / `main:` branch filter; every invoked command exists (`package.json` scripts + stdlib gates).
- Local rehearsal: run EVERY CI step command locally in order and record PASS (they were green in P0-002/003/005/006 — re-run to prove current HEAD state, do not cite stale evidence).

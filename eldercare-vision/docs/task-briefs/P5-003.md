# Task Brief: P5-003 — Evidence Storage + SHA256

- **Task ID:** P5-003
- **Phase:** Phase 5 — FastAPI + PostgreSQL Persistence
- **Role / Skill:** Addy `security-and-hardening`
- **Owner:** IMPL + SEC
- **Status:** IN PROGRESS

## 1. Objectives & Scope

1. **Evidence Storage Engine (`src/eldercare/evidence/storage.py`):**
   - High-performance, secure local media storage for fall snapshots and video clips.
   - Strict path sandboxing preventing directory traversal attacks (`../`, absolute outside paths, null bytes, UNC escapes).
   - Cryptographic SHA-256 integrity calculation and verification during ingestion and retrieval.
   - Chunked streaming I/O to prevent high-memory usage on multi-megabyte video recordings.
   - MIME type resolution and validation for standard media formats (`image/jpeg`, `image/png`, `video/mp4`).
2. **Configuration Support (`src/eldercare/common/settings.py`):**
   - Integration of `EVIDENCE_DIR` with safe default and sanitization.
3. **Automated Testing & Security Validation:**
   - Unit tests for path sandboxing, traversal rejection, and SHA-256 verification (`tests/unit/test_evidence_storage.py`).
   - Security fuzzing / edge case testing for invalid paths and corrupt digests (`tests/unit/test_evidence_security.py`).
   - Integration test with Incident Service (`tests/integration/test_evidence_persistence.py`).

## 2. Invariants & Security Constraints

- **Zero-Traversal Guarantee:** No read, write, or delete operation can resolve to any file outside the canonical configured evidence root directory.
- **Strict Integrity Verification:** Any file content mismatch against expected SHA-256 raises `ChecksumMismatchError` and aborts storage.
- **Fail-Closed Operations:** Non-existent files or invalid parameters raise typed domain exceptions.

## 3. Acceptance Criteria

- All directory traversal vectors (relative parent references, absolute system paths, null bytes) are blocked and tested.
- SHA-256 verification accurately detects both valid writes and corrupted data.
- 100% test pass rate with 0 regressions.
- Ruff lint and formatting remain 100% clean.

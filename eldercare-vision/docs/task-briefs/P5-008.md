# Task Brief: P5-008 — Backend Security Audit & Hardening

- **Task ID:** P5-008
- **Phase:** Phase 5 — FastAPI + PostgreSQL Persistence
- **Role / Skill:** Addy `security-and-hardening`
- **Owner:** SEC
- **Status:** IN PROGRESS

## 1. Objectives & Scope

1. **SQL Injection Resistance Audit:**
   - Verify 100% parameterized SQLAlchemy 2.0 ORM expressions across all repositories and query routers.
   - Probe `/incidents` and `/cameras` with classic and modern SQL injection payloads (`' OR 1=1 --`, `'; DROP TABLE incidents; --`, `UNION SELECT`).
2. **Evidence Sandboxing & Path Traversal Audit:**
   - Audit `EvidenceStorage.resolve_safe_path()` against directory traversal (`../`, `..\\`), root escapes (`/etc/passwd`, `C:\Windows`), null-byte injections (`%00`, `\0`), and absolute path escapes.
   - Verify evidence endpoints resolve media only through verified database entity mappings.
3. **Secret & Credential Redaction Audit:**
   - Audit camera endpoints (`GET /cameras`, `GET /cameras/{camera_id}`) to ensure raw `rtsp_url` is never returned.
   - Audit system telemetry (`GET /system/status`) to ensure database credentials, tokens, and host passwords are never leaked.
4. **Standardized Error Handling & Stack-Trace Suppression:**
   - Audit all exception handlers to ensure unhandled errors return uniform `{"error": {"code": "...", "message": "...", "request_id": "..."}}` with zero Python tracebacks exposed to callers.
5. **Input Length & Structure Hardening:**
   - Audit Pydantic models for bounded string lengths and rejection of unexpected attributes (`extra="forbid"`).
6. **Automated Security Test Suite (`tests/unit/test_backend_security_audit.py`):**
   - Author penetration probes asserting all 5 security dimensions.

## 2. Invariants & Security Constraints

- Zero Critical or Important security findings allowed.
- Zero plaintext credential leakage.
- Zero stack traces exposed over HTTP.

## 3. Acceptance Criteria

- All security penetration tests pass with 100% success rate.
- Security audit report `docs/reviews/P5-008-security-review.md` authored and approved.
- Full repository test suite passes with 0 regressions.

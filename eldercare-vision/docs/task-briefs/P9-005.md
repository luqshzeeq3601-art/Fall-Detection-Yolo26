# P9-005 — Task Brief: Nano Fallback Gate Evaluation

## Objective
Evaluate whether `yolo26s-pose` on TensorRT FP16 meets the production real-time throughput and latency gates on the target NVIDIA GeForce RTX 3070, or if downsizing to the lighter `yolo26n-pose` (Nano) fallback model is warranted per ADR-001 and TASK_SKILL_MATRIX.md.

## Scope
- Performance Gate Criteria:
  - Throughput: >= 30 FPS (real-time camera feed requirement)
  - Mean Latency: <= 33.3 ms
  - p95 Latency: <= 50.0 ms
  - VRAM Footprint: <= 4000 MB (50% of 8GB total VRAM)
- Evidence Base:
  - P9-002 PyTorch baseline: 64.54 FPS, 13.436 ms mean, 14.352 ms p95
  - P9-003 ONNX runtime: 105.33 FPS, 8.377 ms mean, 8.673 ms p95
  - P9-004 TensorRT FP16: 212.91 FPS, 4.125 ms mean, 4.351 ms p95, 12.34 MB peak VRAM
- Decision Threshold:
  - If TensorRT FP16 meets all criteria, the gate PASSES; `yolo26s-pose` is retained as the authoritative production model, and Nano fallback is NOT triggered.
  - If gate fails, trigger Nano fallback export, benchmark, and compile accuracy-throughput trade-off table.

## Requirements & Constraints
- Ground decision strictly in measured benchmark data from P9-002, P9-003, and P9-004.
- Zero model training, zero weight modifications, zero threshold tuning.

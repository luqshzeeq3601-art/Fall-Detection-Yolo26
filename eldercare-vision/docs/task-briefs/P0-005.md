# P0-005 — `.env.example`, secret loading/redaction

## Purpose
Establish the typed configuration boundary: a complete `.env.example`, Pydantic-based settings loading with validation, and secret-redaction helpers. No service integrations — the boundary only.

## Requirements
- `.env.example`: full key set mirroring the Settings model exactly (names + placeholder values, zero real secrets):
  - Required (fail-closed if missing): `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` — names MUST match `docker-compose.yml` `${…:?…}` references verbatim.
  - `DATABASE_URL`: document as compose-derived (`postgresql://${POSTGRES_USER}:…@postgres:5432/${POSTGRES_DB}`); the Settings model must accept it either composed from parts or supplied directly, with exactly one documented precedence (direct value wins if set, else composed — pick one, document it, test it).
  - Optional with safe defaults: `MQTT_HOST` (default `mosquitto`), `MQTT_PORT` (default `1883`), `LOG_LEVEL` (default `INFO`).
  - Optional empty-means-disabled: `RTSP_URL` (empty default; placeholder format comment, no real URL), `VLM_API_KEY` (empty default = enrichment disabled, per NFR-025).
  - Every key gets a one-line comment (purpose + required/optional + default). No other keys without justification.
- `src/eldercare/common/settings.py`: `pydantic-settings` `BaseSettings` model (`model_config = SettingsConfigDict(env_file=".env", extra="ignore")` or equivalent verified against the INSTALLED pydantic-settings version — detect via `pip show pydantic pydantic-settings`, do not rely on remembered API):
  - Typed fields (ports as `int` with range validation, URLs validated, `LOG_LEVEL` as `Literal`), `Optional` only where empty-means-disabled.
  - Missing required → clear `ValidationError` naming the field; malformed values → `ValidationError` (no silent coercion of garbage).
  - A `database_url` property/computed field implementing the documented precedence.
  - A `redacted_summary()`/`safe_dict()` method returning all fields with secrets redacted (uses redaction helpers — never raw values).
- `src/eldercare/common/redaction.py`: pure functions with type hints, no third-party imports:
  - `redact_rtsp_url(url)`: strip `user:password@` userinfo (keep scheme/host/port/path); unparseable input → return a fixed `"<unparseable-url>"` sentinel, never the raw input.
  - `redact_database_url(url)`: same userinfo stripping for `postgresql://` URLs.
  - `redact_token(value)`: show first 2 + `***` + last 2 only if length ≥ 8, else full `"***"`; empty/None → `"***"`.
  - `redact_mapping(d, sensitive_keys)`: redact dict values for a caller-supplied key set (case-insensitive match on `password|passwd|secret|token|api_key|apikey|auth` by default).
  - `sanitize_exception_message(msg)`: apply URL + token redaction to arbitrary error text so exceptions/logs never leak credentials.
- Declare `pydantic>=2` and `pydantic-settings>=2` in `[project] dependencies` (first runtime deps; lower bounds must be ≤ installed versions: pydantic 2.13.4, pydantic-settings 2.15.0 — verify locally). `pip install -e .`, `ruff check`, `ruff format --check`, `pytest` must all pass with the new code (type hints on all public functions per AGENTS.md §9; no bare `except`).
- Tests (TDD, RED first): `tests/unit/test_settings.py` + `tests/unit/test_redaction.py` covering at minimum:
  1. missing each required var → `ValidationError` (parametrized);
  2. malformed `MQTT_PORT` (non-numeric / out of range) → `ValidationError`;
  3. malformed `RTSP_URL` (not a URL) → `ValidationError` when set;
  4. `DATABASE_URL` precedence (direct vs composed) both directions;
  5. RTSP redaction: `rtsp://user:pass@host:554/stream` → userinfo gone, host/port/path intact; unparseable → sentinel;
  6. postgres URL redaction preserves host/db, strips password;
  7. token redaction short/long/empty cases;
  8. `redact_mapping` case-insensitive key matching, non-sensitive keys untouched;
  9. exception/log safety: `str(exc)` and a formatted log line containing a credentialed URL show no password after `sanitize_exception_message`;
  10. `.env.example`↔model↔compose reconciliation test: every `POSTGRES_*` name in compose exists in the model and the example file (parse all three in-test; no hardcoded duplicate list).
- MIT-license placeholder: leave untouched (tracked P12 follow-up).

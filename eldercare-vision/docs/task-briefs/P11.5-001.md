# P11.5-001 — Task Brief: Baseline Snapshot & Learning vs Engineering Scoping

## Objective
Establish an immutable snapshot of the verified Phase 11 baseline state, configure the Phase 11.5 experiment namespace, and perform an evidence-based technical scoping of learning vs. engineering interventions based on the P11-006 error and limitations analysis.

## Scope
1. **Baseline Snapshot**:
   - Record baseline git commit `84bfb2c`.
   - Snapshot cryptographic digests for `yolo26s-pose.pt`, `yolo26s-pose.onnx`, `yolo26s-pose.engine`, `config/fall_detection.yaml`, and dataset manifests.
   - Record baseline evaluation metrics: URFD (TP=1, FP=10, TN=6, FN=11, F1=8.70%), UP-Fall (TP=0, FP=0, TN=7, FN=8, F1=0.00%), Combined (F1=6.45%, False alerts=175.07/hr), and Local UAT (20/20 PASS).
   - Author `docs/reports/P11.5-001-baseline-snapshot.json`.
2. **Learning vs. Engineering Scoping**:
   - Inspect failure mechanisms from `docs/reports/P11-006-error-limitations-analysis.md`.
   - Evaluate YOLO26s-Pose fine-tuning feasibility: Determine if 17-keypoint COCO-format pose annotations are available. Confirm that URFD/UP-Fall lack keypoint annotations and require freezing the pose backbone (`yolo26s-pose.pt/engine`) to avoid corrupting general pose estimation.
   - Formulate temporal fall layer improvements:
     - Scale-normalized velocity features (dividing displacement by dynamic upright person height and bbox diagonal).
     - Adaptive aspect ratio and torso angle geometry (invariant to camera distance and subject stature).
     - Low posture floor proximity and sustained ground persistence.
     - ByteTrack ID-switch resilience.
     - Lightweight learned temporal classifier trained on derived features from development partitions only.
3. **Anti-Leakage Governance**:
   - Enforce strict quarantine: all training, feature calibration, model selection, and hyperparameter tuning MUST use ONLY development partitions (`dev` split in URFD, UP-Fall, and Local).
   - Zero access to final test split sequences (`test` split) during candidate development.

# Task Brief: P5-007 — Real-Time WebSocket Event Streaming

- **Task ID:** P5-007
- **Phase:** Phase 5 — FastAPI + PostgreSQL Persistence
- **Role / Skill:** Addy `api-and-interface-design`
- **Owner:** IMPL + TEST
- **Status:** IN PROGRESS

## 1. Objectives & Scope

1. **Structured WebSocket Event Envelope (`src/eldercare/api/schemas.py`):**
   - Implement `WebSocketEvent` model conforming to `API_SPEC.md` §6:
     - `event_id`: Unique UUID.
     - `event_type`: Event identifier (`fall.confirmed`, `fall.started`, `fall.ended`, `camera.status`, `incident.reviewed`, `system.heartbeat`).
     - `occurred_at`: ISO 8601 UTC timestamp.
     - `camera_id`: Optional associated camera ID.
     - `incident_id`: Optional associated incident ID.
     - `payload`: Structured arbitrary dictionary payload.
2. **Asynchronous Connection Manager (`src/eldercare/api/ws.py`):**
   - Thread-safe / async connection registry managing active client connections.
   - Resilient broadcasting mechanism: dead or aborted sockets are cleanly pruned without blocking active listeners.
   - Provides methods `connect(websocket)`, `disconnect(websocket)`, and `broadcast(event)`.
3. **WebSocket Route Endpoint (`src/eldercare/api/routers/websocket.py`):**
   - Expose `WS /ws/events` (and `/api/v1/ws/events`).
   - Accepts connection, handles ping/pong or client keepalive messages, and cleans up on `WebSocketDisconnect`.
4. **Application Wiring & Re-exports (`src/eldercare/api/app.py`, `src/eldercare/api/__init__.py`):**
   - Mount router and attach `ConnectionManager` to `app.state.connection_manager`.
   - Re-export `WebSocketEvent` and `ConnectionManager`.
5. **Comprehensive Automated Tests (`tests/unit/test_api_websocket.py`):**
   - Connect and receive broadcasted events.
   - Multi-client concurrency test (broadcast delivered to all active clients).
   - Clean disconnection handling and connection count tracking.
   - Ping/pong keepalive messages.

## 2. Invariants & Security Constraints

- **Strict Schema Conformance:** All broadcasted messages must adhere to the `API_SPEC.md` §6 envelope.
- **Resource Protection & Graceful Error Handling:** Dead socket disconnections must never raise uncaught server exceptions or cause memory leakage.
- **In-Memory Determinism:** Tests run fast and locally without network sockets or external brokers.

## 3. Acceptance Criteria

- `WS /ws/events` connects and receives structured `WebSocketEvent` envelopes.
- Connection manager broadcasts to multiple connected clients in parallel.
- Client disconnects cleanly clean up state.
- 100% test pass rate with 0 regressions.
- Ruff lint and formatting 100% clean.

# P11.7-003 — Task Brief: Real Decoded-Video Evaluator & V3-as-is Real Baseline

## Objective
Establish the honest, empirical **V3-as-is** baseline on genuine recorded video footage (URFD benchmark) using the complete production path:
Real video -> OpenCV decoding -> YOLO26s-Pose TensorRT FP16 -> ByteTrack -> V3 Features -> LogisticClassifierV3 -> TrackFallStateMachineV3.

Report all measured metrics transparently regardless of outcome, replacing quarantined synthetic claims with empirical truth.

## Scope
- `scripts/dataset/evaluate_v3_real_decoded.py`:
  - Genuine video decoding via OpenCV.
  - Hardware accelerated pose estimation using `yolo26s-pose.engine` on NVIDIA GeForce RTX 3070.
  - Multi-person ByteTrack tracking.
  - Full V3 temporal feature extraction and state machine update.
  - Extraction of true frame counts, actual processed seconds, time-to-alert, usable pose availability, track continuity, and ID switches.
- `docs/reports/P11.7-003-v3-asis-real-evaluation.json`:
  - Immutable per-sequence evaluation ledger with video SHA-256 hashes, frame counts, latency, and classifications.
- `docs/reports/P11.7-003-v3-asis-real-report.md`:
  - Comprehensive markdown report comparing empirical V3-as-is against deployment SLAs.

## Acceptance Criteria
1. Evaluator processes genuine recorded videos frame-by-frame (no synthetic generator or label substitution).
2. All 28 held-out test sequences from URFD evaluated with zero cross-video state leakage.
3. Every metric computed via `DeploymentMetricsV4` with `provenance="real_measured"` and full source hash locks.
4. Output ledger records exact frame counts, decoded seconds, and SHA-256 digests.
5. All code passes `ruff check` and `ruff format --check`.
6. Independent review approval with 0 Critical / 0 Important findings.

# P11.5-005 — Task Brief: Untouched Frozen Re-Evaluation

## Objective
Re-evaluate the frozen Fall Detection Engine V2 (Candidate 3) on the untouched test partitions of the URFD (28 sequences), UP-Fall (15 sequences), and Local (5 sequences) datasets using the frozen TensorRT FP16 runtime. Calculate precision, recall, F1 score, accuracy, time-to-alert, and false alarm rate under strict zero-leakage conditions, generating comprehensive raw evaluation ledgers and summary reports.

## Scope
1. **Partitions Evaluated**:
   - URFD Test Split: 28 sequences (12 Falls, 16 ADLs).
   - UP-Fall Test Split: 15 sequences (8 Falls, 7 ADLs, Camera1 RGB).
   - Local Test Split: 5 sequences (2 Falls, 3 ADLs).
2. **Model Pipeline**:
   - Frozen YOLO26s-Pose TensorRT engine (`yolo26s-pose.engine`).
   - Frozen Temporal Fall Classifier V2 (`models/temporal_fall_classifier_v2.json`).
   - Frozen Fall State Machine V2 (`config/fall_detection_v2.yaml`).
3. **Strict Constraints**:
   - Zero modification of test split manifests or video contents.
   - Zero parameter tuning during or after test partition evaluation.
4. **Deliverables**:
   - `docs/reports/P11.5-005-urfd-raw-evaluation.json`
   - `docs/reports/P11.5-005-upfall-raw-evaluation.json`
   - `docs/reports/P11.5-005-final-metrics.json`
   - `docs/reports/P11.5-005-final-metrics-report.md`
   - `docs/task-briefs/P11.5-005.md`
   - `docs/task-reports/P11.5-005.md`
   - `docs/reviews/P11.5-005-review.md`

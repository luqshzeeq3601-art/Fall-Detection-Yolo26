# P4-004 — Confidence Score, Persistence, Cooldown: Task Brief

## 1. Objective
Implement the explainable confidence scoring engine, evidence breakdown, and incident cooldown manager for ElderCare Vision according to `AI_SPEC.md` §8 & §10 and `ACCEPTANCE_CRITERIA.md` (AC-024, AC-025, AC-026).

## 2. Requirements & Specifications
- **Confidence Scoring (`AI_SPEC.md` §8)**:
  - $\text{Score} = w_{\text{motion}} \cdot S_{\text{motion}} + w_{\text{posture}} \cdot S_{\text{posture}} + w_{\text{persistence}} \cdot S_{\text{persistence}} - P_{\text{keypoint}} - P_{\text{track}}$
  - Clamped to $[0.0, 1.0]$.
  - Weights and thresholds live in `FallConfidenceConfig` (no hardcoded magic constants).
- **Evidence Breakdown & Explainability (`AI_SPEC.md` §10)**:
  - Records full component scores ($S_{\text{motion}}$, $S_{\text{posture}}$, $S_{\text{persistence}}$), penalties ($P_{\text{keypoint}}$, $P_{\text{track}}$), key contributing metrics, average pose confidence, detector model, tracker name, config version.
- **Incident Cooldown Manager**:
  - Enforces configurable per-track and per-camera cooldown windows (default 5.0s) to prevent duplicate alert storms.
- **State Machine Integration**:
  - `FallEvent` includes the structured `FallConfidenceBreakdown`.
  - Missing keypoints degrade confidence safely without exceptions (AC-026).

## 3. Implementation Targets
- `src/eldercare/fall_engine/confidence/calculator.py` (`FallConfidenceBreakdown`, `FallConfidenceConfig`, `compute_fall_confidence`)
- `src/eldercare/fall_engine/confidence/cooldown.py` (`IncidentCooldownManager`, `CooldownConfig`)
- `src/eldercare/fall_engine/confidence/__init__.py`
- Integration in `src/eldercare/fall_engine/state_machine/machine.py` and `states.py`
- Re-exports in `src/eldercare/fall_engine/__init__.py`

## 4. Verification Plan
- Unit tests: Component scores, missing keypoint penalty, track jitter penalty, clamping $[0, 1]$, cooldown suppression, cooldown expiry, custom weights.
- Integration tests: End-to-end full sequence event generation with rich confidence breakdown and cooldown verification.
- Linter & AST scans.

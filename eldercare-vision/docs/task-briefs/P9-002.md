# P9-002 — Task Brief: PyTorch Baseline Benchmark on NVIDIA RTX 3070

## Objective
Measure the real PyTorch CUDA baseline inference performance using `yolo26s-pose.pt` on the verified NVIDIA GeForce RTX 3070 GPU host, following the reproducible benchmark harness established in P9-001.

## Scope
- Predictor: real `UltralyticsPosePredictor` (`yolo26s-pose.pt`, `device=0`, `imgsz=640`)
- Framework: PyTorch 2.5.1+cu121, CUDA 12.1, cuDNN 9.1.0, Ultralytics 8.4.142
- Hardware: NVIDIA GeForce RTX 3070 8GB
- Harness: `benchmarks/scripts/benchmark_inference.py` (warmup=40, frames=300, reps=3, seed=42)
- Artifact: `benchmarks/results/p9_002_pytorch_baseline.json`

## Requirements & Constraints
- Must record: FPS, mean latency, p50, p90, p95, p99, inference latency, per-stage latency, VRAM peak, RSS peak, environment, and CV variability.
- Must preserve 17-keypoint contract and pipeline integrity without altering production code.
- Zero model training, zero weight modifications, zero threshold modifications.

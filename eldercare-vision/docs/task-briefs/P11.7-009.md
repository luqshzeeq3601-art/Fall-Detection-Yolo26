# P11.7-009 — Task Brief: Threshold Calibration on Dev Split Only

## Objective
Calibrate the fall detection engine operating thresholds (trigger threshold, confirmation threshold, and false-alert veto threshold) strictly using the isolated development partition (`datasets/cache/v4_dev_features.npz`, 42 genuine optical sequences across subjects `subj-01` to `subj-06`). Generate quantitative Precision-Recall, ROC, and $F_\beta$ ($\beta=1, \beta=2$) calibration curves. Determine the optimal operational operating triplet $(\tau_{\text{veto}}, \tau_{\text{trigger}}, \tau_{\text{confirm}})$ that balances high sensitivity ($\ge 90\%$ on fall descent/impact) with maximal specificity on complex ADLs (sitting down, picking up objects, crouching, lying down slowly). Emit `config/fall_detection_v4.yaml` and publish the formal calibration report at `docs/reports/P11.7-009-threshold-calibration-report.md`.

## Scope
1. **Calibration Engine (`src/eldercare/fall_engine/calibration/calibrator_v4.py`):**
   - `ThresholdCalibratorV4`: Computes PR curves, ROC curves, optimal $F_1$ and $F_2$ operating points, and ADL false alert rates across a grid of thresholds $T \in [0.05, 0.95]$.
   - `ThresholdTriplet`: Data model encapsulating `(veto_threshold, trigger_threshold, confirmation_threshold)` with operating guarantees.
   - `OperatingCurveSummary`: Structured summary of TPR, FPR, Precision, Recall, and F-scores.
2. **CLI Calibration Runner (`scripts/calibration/calibrate_v4_thresholds.py`):**
   - Enforces `DatasetSplitGuard.enforce_training_isolation("dev")`.
   - Evaluates frozen `GRUClassifierV4` (`models/temporal_fall_classifier_v4.json`) over all 8,735 dev samples.
   - Searches for optimal triplet maximizing F2 subject to Sensitivity $\ge 90.0\%$ and ADL Specificity $\ge 95.0\%$.
   - Writes production configuration to `config/fall_detection_v4.yaml`.
   - Generates markdown audit report at `docs/reports/P11.7-009-threshold-calibration-report.md`.
3. **Unit Test Suite (`tests/unit/test_v4_threshold_calibration.py`):**
   - Verifies PR and ROC curve computations on synthetic and real probability distributions.
   - Verifies monotonic threshold sweep and bounds checks ($0.0 < \tau_{\text{veto}} \le \tau_{\text{trigger}} \le \tau_{\text{confirm}} < 1.0$).
   - Verifies strict isolation enforcement (preventing access to test split).
   - Verifies valid generation and schema compliance of `config/fall_detection_v4.yaml`.
4. **Independent Quality Review:**
   - Formal review gate documenting zero Critical / Important findings in `docs/reviews/P11.7-009-review.md`.

## Acceptance Criteria
1. Strict adherence to split isolation: zero test or holdout samples accessed during calibration.
2. Calibration curves (PR, ROC, F2) generated across complete threshold spectrum.
3. Optimal operational point achieves development Sensitivity $\ge 90.0\%$ and ADL Specificity $\ge 95.0\%$.
4. Valid operational triplet satisfying $\tau_{\text{veto}} \le \tau_{\text{trigger}} \le \tau_{\text{confirm}}$.
5. Valid production configuration emitted to `config/fall_detection_v4.yaml`.
6. Formal report published at `docs/reports/P11.7-009-threshold-calibration-report.md`.
7. Zero regression to quarantined artifacts (`test_evidence_quarantine.py` passes 100%).
8. All unit tests pass and code is clean under `ruff check`.
9. Independent review APPROVE with 0 Critical and 0 Important findings.

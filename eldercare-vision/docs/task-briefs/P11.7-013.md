# Task Brief: P11.7-013 — Camera Orientation & Height Invariance

## 1. Context & Objectives
Residential eldercare facilities install monitoring cameras across wide mounting configurations:
- Ceiling mounts (2.8m, pitch 30°–45°)
- Wall corner mounts (2.2m–2.4m, pitch 20°–30°)
- Low furniture / table setups (1.0m–1.5m, near-horizontal)

Perspective distortion introduces spatial variance:
- Vertical velocities in pixel space compress as downward camera pitch increases ($\propto \cos \theta_p$).
- Subject distance dramatically alters apparent bounding box height.
- Projected 2D torso angles deviate from true 3D gravity-aligned posture angles.

This task delivers a comprehensive perspective rectification and height normalization module (`CameraPerspectiveNormalizer`) to establish multi-camera invariant fall detection dynamics.

---

## 2. Technical Scope
- **`src/eldercare/fall_engine/normalization/camera_normalizer.py`:**
  - `CameraNormalizationConfig`: Explicit camera parameters (height, pitch, roll, focal length) and auto-calibration flags.
  - `CameraPerspectiveNormalizer`:
    - Metric distance estimation from bounding box scaling and ground-plane ray geometry.
    - True gravity-aligned vertical velocity rectification ($\frac{v_y}{\cos \theta_p}$).
    - Perspective-compensated 3D torso angle projection.
    - Auto-calibration of pitch angle from upright standing track statistics.

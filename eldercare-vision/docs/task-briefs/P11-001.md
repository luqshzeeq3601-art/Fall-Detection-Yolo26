# P11-001 — Task Brief: Freeze Final Evaluation State

## Objective
Establish an immutable cryptographic freeze manifest binding git commits, model checkpoints, runtime engines, configurations, hardware specifications, and dataset split definitions before initiating Phase 11 final evaluation, enforcing complete anti-leakage invariants.

## Scope
1. **Cryptographic Binding**:
   - Git commit hash, branch, clean status.
   - Model checkpoint hashes (`yolo26s-pose.pt`, `yolo26s-pose.onnx`, `yolo26s-pose.engine`).
   - Configuration file hashes (`config/fall_detection.yaml`).
   - Dataset manifest hashes (`urfd_manifest.csv`, `upfall_manifest.csv`, `local_manifest.csv`).
2. **Environment & Runtime Provenance**:
   - Hardware: NVIDIA GeForce RTX 3070 8GB, driver `616.92`.
   - Software: Python `3.10.11`, PyTorch `2.5.1+cu121`, CUDA `12.1`, TensorRT `11.3.0.99`, Ultralytics `8.4.142`.
   - Primary inference runtime: TensorRT 11 FP16 (per ADR-006).
   - Tracker: stock ByteTrack (`bytetrack.yaml`).
   - Agent/VLM: Prompt template `v1.0.0`, Schema `1.0.0`.
3. **Anti-Leakage & Split Integrity Verification**:
   - Verify URFD 42 dev / 28 test sequence-disjoint partition.
   - Verify UP-Fall subject-disjoint partition (subjects 1-5 dev vs 12-17 test, 27 dev / 15 test).
   - Verify Local 7 dev / 5 test sequence-disjoint partition (12 total).
   - Confirm test split has zero threshold tuning influence.
4. **Deliverables**:
   - Manifest: `docs/reports/P11-001-freeze-manifest.json` and `datasets/freeze_manifest.json`.
   - Verification test: `tests/unit/test_phase11_freeze_manifest.py`.
   - Task brief, task report, review.

## Constraints
- Once frozen, zero modifications to fall thresholds, tracker parameters, model weights, or split memberships.
- Zero model training, zero fine-tuning.

# P11.7-005 — Task Brief: Wiring Fixes W1–W6 and V3-Fixed-Real Baseline

## Objective
Remediate the six production wiring defects (W1–W6) identified in P11.7-001 without retraining model weights, verify each fix with targeted unit tests, and measure the empirical **V3-fixed-real** baseline on genuine URFD test video to assess impact relative to the V3-as-is baseline.

## Scope
1. **W1 (Feature Skew):** Pass the complete 24-feature vector `TemporalFeaturesV3.feature_vector` into `LogisticClassifierV3`, preserving floor proximity (`f_15`) and dynamics; enforce strict dimension checking in `LogisticClassifierV3.predict_probability`.
2. **W2 (Config Unification):** Establish `config/fall_detection_v3.yaml` and `FallStateMachineConfigV3` as the single unambiguous source of truth for runtime thresholds, removing conflicting threshold literals.
3. **W3 (Two-Stage Confirmation & Veto):** End classifier OR-only alert behavior; implement two-stage confirmation where low classifier probability actively vetoes heuristic false alerts.
4. **W4 (V3 Default Classifier):** Point `TrackFallStateMachineV3` and `FallStateMachineManagerV3` default factory to `LogisticClassifierV3` with automatic weight discovery.
5. **W5 (Track Stitching & ByteTrack Config):** Wire `TrackStitcher` into track management for short occlusions/gaps ($\le 15$ frames) and configure custom ByteTrack parameters via `config/bytetrack_v3.yaml`.
6. **W6 (Feature Schema Improvements):** Expose scale-normalized stability and keypoint confidence metadata in `TemporalFeaturesV3`.
7. **Empirical Measurement:** Build `scripts/dataset/evaluate_v3_fixed_real.py` and evaluate all 28 real URFD test sequences on RTX 3070 with TensorRT FP16 YOLO26s-Pose and locked evidence artifacts:
   - `docs/reports/P11.7-005-v3-fixed-real-evaluation.json`
   - `docs/reports/P11.7-005-v3-fixed-real-report.md`
8. **Unit Tests:** `tests/unit/test_wiring_fixes.py` covering W1–W6.

## Acceptance Criteria
1. Full 24 features delivered to classifier; dimension mismatches raise explicit error.
2. Thresholds unified across YAML and dataclass without silent overrides.
3. Veto logic successfully suppresses non-fall false alerts while preserving true positive triggers.
4. V3 state machine defaults cleanly to V3 classifier without referencing V2 model weights.
5. Track stitching handles track gaps without state drops or identity corruption.
6. All 28 real URFD test sequences evaluated without retraining; metrics recorded via `DeploymentMetricsV4` with `provenance="real_measured"`.
7. Zero modification to quarantined artifacts (`tests/unit/test_evidence_quarantine.py` passes).
8. All code passes `ruff check` and `ruff format --check`.
9. Independent review approval with 0 Critical / 0 Important findings.

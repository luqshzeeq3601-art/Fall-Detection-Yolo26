# P11-004 — Task Brief: Local Camera & System UAT Execution

## Objective
Execute the full suite of User Acceptance Testing (UAT) scenarios defined in `UAT_PLAN.md` (UAT-01 through UAT-20) against the frozen ElderCare Vision system, verifying end-to-end operational behavior across ADL movements, fall detection, multi-person tracking, system fault recovery, and data immutability without physical injury risk or detector tuning.

## Scope
1. **Scenario Execution**:
   - Execute all 20 critical scenarios in `tests/system/test_uat_critical.py`.
   - Validate normal ADL movements (walking, sitting, standing, bending, kneeling, slow lie down).
   - Validate fall transitions (rapid fall, sustained down, recovery).
   - Validate edge conditions (partial occlusion, multi-person, low light).
   - Validate system fault tolerance (camera drop/reconnect, MQTT failure, VLM timeout, dashboard close, backend restart, extended runtime).
2. **Evidence Recording**:
   - Generate `docs/reports/P11-004-uat-report.md`.
   - Complete `docs/task-reports/P11-004.md` and `docs/reviews/P11-004-review.md`.

## Constraints & Invariants
- Zero model retraining, fine-tuning, or threshold modification.
- Absolute physical safety: rely on controlled pre-recorded footage and deterministic test harnesses.
- Any truly unavailable technical scenario must be marked BLOCKED rather than falsely passed.

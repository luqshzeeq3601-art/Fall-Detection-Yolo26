# P2-002 — Load `yolo26s-pose.pt`

## Purpose
Prove the pinned model loads and predicts on the RTX 3070 via the official Ultralytics inference workflow: download exactly `yolo26s-pose.pt`, run one minimal real CUDA prediction on a small controlled image, and verify the Results carry 17-keypoint human pose with confidences. Load-proof only — no adapter, no integration, no benchmarks.

## Requirements
- Source-driven (cite in report): the exact Ultralytics inference call pattern verified against the INSTALLED 8.4.142 package (`YOLO` import path, `predict`/`model()` signature, `device` argument spelling, `Results.keypoints` attribute layout — confirm by inspecting installed source/help, not memory). Record package path + relevant signatures.
- One runnable script `scripts/dev/verify_pose_model.py` (stdlib + ultralytics + numpy only; argparse for `--image` and `--device` with defaults `bus.jpg`-canonical + `0`):
  - Loads `YOLO("yolo26s-pose.pt")` ( triggers the single sanctioned weights download on first run — exactly this file, nothing else).
  - Runs prediction with explicit `device=0`, `imgsz=640` (per CONSTRAINTS defaults), `verbose=False`.
  - Test image: the canonical Ultralytics `bus.jpg` (contains people) — script downloads it from the official URL ONLY if no local copy is supplied via `--image`; records provenance (URL + byte size + sha256) in stdout + report. No dataset downloads, no other images.
  - Prints a structured field block (the acceptance record): checkpoint identity (model name + task), weights cache path, `model.device`, input size, detected person count (must be ≥1 or the run FAILS), `keypoints.xy` shape (must be `(N, 17, 2)`), `keypoints.conf` shape (`(N, 17)`), keypoint device (must be `cuda:0`), plus `boxes` shape for context.
  - Asserts (hard failures, non-zero exit): person count ≥ 1; `xy.shape[1] == 17`; conf present with matching shape; keypoint tensor device type is CUDA. Any assertion failure = task failure, not a warning.
- Weights/cache hygiene: the downloaded `.pt` MUST live outside the repo (Ultralytics default cache); prove with `git status --short` (no weights) + `git check-ignore -v <weight-path>` (ignored) + record the absolute cache path. `.gitignore` already covers `*.pt`/`weights/` — extend ONLY if the proof shows a gap.
- No pytest additions in this task (a download+GPU test would break CPU-only CI; P2-006 owns regression tests). The Tester verifies by re-running the script and diffing outputs.
- Record in report: full stdout transcript, model/device/shapes table, cache path, image provenance, Ultralytics call-pattern citations, assumptions (e.g. first-run downloads weights — network required once), limitations.

# P10-004 — Task Brief: Structured Prompt, Output Schema, and Versioning

## Objective
Implement structured, version-controlled prompt templates and strict Pydantic output validation schemas for Agent/VLM incident enrichment.

## Scope
- **Prompt Catalog (`src/eldercare/agents/prompts.py`)**:
  - Versioned prompt templates (`DEFAULT_PROMPT_VERSION = "v1.0.0"`).
  - Explicit system guidance instructing the VLM to observe postural state, environmental hazards, motion context, and scene composition without hallucinating or rendering medical diagnoses.
  - Prompt registry and builder function `build_enrichment_prompt(...)`.
- **Output Validation Schema (`src/eldercare/agents/schemas.py`)**:
  - Strict Pydantic v2 `EnrichmentOutputSchema` model forbidding unexpected extra fields.
  - Standardized enums: `ConfidenceLevel` and `PosturalState`.
  - Comprehensive fields: `schema_version`, `posture_description`, `apparent_motion_context`, `environmental_context`, `scene_summary`, `confidence_assessment`, `uncertainty_factors`, `postural_state`, `potential_hazards`.
  - Fail-closed parsing helper `parse_and_validate_enrichment_output(...)`.
- **Unit & Schema Validation Suite (`tests/unit/test_agent_schemas.py`)**:
  - Test valid schemas, missing required fields, enum enforcement, extra field rejection, string-to-dict parsing, and prompt version catalog lookup.

## Constraints
- Do not alter detector thresholds, models, or core fall detection pipeline.
- Ensure all models strictly forbid arbitrary/extra payload injection (`extra = "forbid"`).

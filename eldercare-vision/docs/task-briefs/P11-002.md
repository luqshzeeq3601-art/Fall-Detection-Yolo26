# P11-002 — Task Brief: URFD Final Evaluation

## Objective
Execute end-to-end evaluation of the frozen ElderCare Vision inference pipeline (TensorRT 11 FP16 YOLO26s-Pose + ByteTrack + Temporal Fall Engine) against the 28 held-out test sequences from the official UR Fall Detection Dataset (URFD), generating immutable raw detection ledgers and classification counts without threshold or model parameter tuning.

## Scope
1. **Dataset Reconciliation**:
   - Verify all 28 URFD test sequences (12 falls: `fall-19-cam0.mp4`..`fall-30-cam0.mp4`, 16 ADLs: `adl-25-cam0.mp4`..`adl-40-cam0.mp4`) are present on disk, readable, decodable, and non-corrupt.
   - Verify 0% sequence overlap with the 42 development sequences.
   - Generate reconciliation report: `docs/reports/P11-002-urfd-dataset-reconciliation.json`.
2. **Frozen Pipeline Execution**:
   - Process each test sequence through: Video Decode -> YOLO26s-Pose TensorRT 11 FP16 (640x640) -> ByteTrack -> Temporal Fall Engine (`fall_detection.yaml` frozen config).
   - Zero parameter changes or runtime modifications.
3. **Per-Sequence Raw Evidence Capture**:
   - Record exact sequence ID, ground truth, prediction, TP/FP/TN/FN classification, incident timestamps, confidence scores, time-to-alert (where authoritative onset exists), and diagnostic failure flags in `docs/reports/P11-002-urfd-raw-evaluation.json`.
4. **Metric Compilation & Documentation**:
   - Calculate raw TP, FP, TN, FN counts.
   - Author human-readable evaluation report `docs/reports/P11-002-urfd-evaluation-report.md`.
   - Complete task report `docs/task-reports/P11-002.md` and review `docs/reviews/P11-002-review.md`.

## Constraints & Invariants
- Zero model training, zero fine-tuning, zero weight updates.
- Zero threshold tuning on test data; unexpected results are recorded faithfully as empirical evidence.
- Evaluate ONLY the 28 test split sequences.

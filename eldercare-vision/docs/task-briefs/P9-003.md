# P9-003 — Task Brief: ONNX Export and Benchmark on NVIDIA RTX 3070

## Objective
Export `yolo26s-pose.pt` to ONNX format (opset 18, onnxslimmed), validate correctness and 17-keypoint contract parity against the PyTorch baseline, and benchmark ONNX Runtime CUDA inference performance on NVIDIA GeForce RTX 3070 8GB using the reproducible harness.

## Scope
- Model export: `yolo26s-pose.onnx` (opset 18, onnxslim enabled, imgsz=640)
- Predictor: `UltralyticsPosePredictor` (`yolo26s-pose.onnx`, ONNX Runtime 1.23.2 with `CUDAExecutionProvider`)
- Validation: Verify 17 keypoint outputs shaped `(N, 17, 2)` and confidence `(N, 17)` match production expectations.
- Harness: `benchmarks/scripts/benchmark_inference.py` (warmup=40, frames=300, reps=3, seed=42)
- Artifact: `benchmarks/results/p9_003_onnx.json`
- Report: `docs/reports/P9-003-benchmark-report.md`

## Requirements & Constraints
- Must record: FPS, mean latency, p50, p90, p95, p99, synchronized inference latency, per-stage latency, VRAM peak, RSS, environment, and CV across runs.
- Must compare directly with P9-002 PyTorch baseline under identical workload conditions.
- Zero model training, zero fine-tuning, zero weight alterations, zero threshold tuning.

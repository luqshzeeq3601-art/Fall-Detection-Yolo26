# P11.7-006 — Task Brief: Real Multi-Source Dataset Acquisition & Ingestion Protocol

## Objective
Formulate and implement the V4 real multi-source dataset acquisition & ingestion protocol under the governance established in P11.7-004. Ingest legally cleared genuine optical camera datasets, compute cryptographic SHA-256 digests, extract video metadata, enforce optical authenticity validation (detecting and barring synthetic renders), parse temporal fall annotations, compile a unified master V4 manifest (`datasets/manifests/v4_multi_source_manifest.json` and `.csv`), and verify subject-disjoint split isolation under `DatasetSplitGuard`.

## Scope
1. **Ingestion Engine (`src/eldercare/fall_engine/dataset/ingestion.py`):**
   - `OpticalAuthenticityValidator`: Analyzes frame color depth, gradient variance, and sensor noise to differentiate authentic optical camera captures from flat synthetic renders.
   - `IngestedVideoMetadata`: Comprehensive metadata dataclass tracking sample_id, source_dataset, sequence_id, subject_id, camera_id, activity, is_fall, fall_type, path_local, split, license, sha256, frame_count, fps, duration_sec, width, height, codec, deployment_evidence, optical_authenticity_score, and temporal annotations (`fall_start_frame`, `fall_end_frame`, `lying_start_frame`).
   - `DatasetIngestionEngine`: Coordinates scanning, metadata extraction, cryptographic hashing, authenticity checks, temporal annotation alignment, and manifest generation.
2. **Dataset Ingestion Runner (`scripts/dataset/ingest_v4_datasets.py`):**
   - Command-line utility to execute ingestion across raw datasets, verify integrity, and output structured summaries.
3. **Master Ingestion Manifest:**
   - `datasets/manifests/v4_multi_source_manifest.json` and `datasets/manifests/v4_multi_source_manifest.csv` registering all 70 genuine URFD videos (42 dev, 28 test) with ground-truth temporal intervals, verified SHA-256 digests, and split tags.
4. **Quarantined Synthetic Isolation:**
   - Enforce that synthetic stick figures (such as legacy UP-Fall OpenCV renders) are strictly barred from `deployment_evidence=True`.
5. **Ingestion Report:**
   - `docs/reports/P11.7-006-dataset-ingestion-report.md`: Complete audit report detailing dataset provenance, licensing, frame counts, SHA-256 hashes, and split isolation proofs.
6. **Unit Test Suite:**
   - `tests/unit/test_v4_dataset_ingestion.py`: Testing optical authenticity discrimination, full URFD manifest verification, temporal annotation parsing, split isolation with `DatasetSplitGuard`, tamper detection, and synthetic rejection.

## Acceptance Criteria
1. Optical authenticity check reliably distinguishes genuine optical sensor capture from flat synthetic renders.
2. Ingests all 70 raw URFD videos with accurate metadata (width, height, fps, frame count, duration, sha256).
3. Ground truth temporal fall boundaries parsed for all 30 fall sequences from official CSV.
4. Programmatic split isolation verified via `DatasetSplitGuard` with zero subject overlap between dev (6 subjects) and test (4 subjects).
5. Tamper-evident hash validation detects modified or corrupted video files.
6. Zero modification or regression to quarantined artifacts (`tests/unit/test_evidence_quarantine.py` passes 100%).
7. All new code passes `ruff check` and unit tests pass.
8. Independent review approval with 0 Critical / 0 Important findings.

# P9-006 — Task Brief: Production Inference Runtime Selection ADR

## Objective
Author the formal Architectural Decision Record (ADR-006) for production inference runtime selection on NVIDIA RTX 3070 and multi-platform deployments, grounded entirely in measured empirical data from P9-002 (PyTorch), P9-003 (ONNX), and P9-004 (TensorRT FP16).

## Scope
- Compare all evaluated runtime candidates under identical workload conditions on the target NVIDIA GeForce RTX 3070 8GB.
- Clearly separate MEASURED FACTS (FPS, latency percentiles, memory, artifact sizes, correctness) from ENGINEERING DECISIONS (runtime hierarchy, fallback strategy, build pipeline).
- Document the primary runtime recommendation (TensorRT FP16), primary fallback runtime (ONNX Runtime CUDA/CPU), and golden reference (`yolo26s-pose.pt`).

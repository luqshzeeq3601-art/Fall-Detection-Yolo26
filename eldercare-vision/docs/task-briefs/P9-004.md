# P9-004 — Task Brief: TensorRT FP16 Export and Benchmark on NVIDIA RTX 3070

## Objective
Export `yolo26s-pose.pt` to TensorRT FP16 engine format (`yolo26s-pose.engine`), validate 17-keypoint accuracy and detection contract parity, and benchmark inference performance on NVIDIA GeForce RTX 3070 8GB using the reproducible benchmark harness.

## Scope
- Model export: `yolo26s-pose.engine` (TensorRT 11.3.0.99 strongly-typed FP16, imgsz=640)
- Predictor: `UltralyticsPosePredictor` (`yolo26s-pose.engine`, device=0, imgsz=640)
- Validation: Verify 17 keypoint outputs shaped `(N, 17, 2)` and confidence `(N, 17)` match production expectations on sample data.
- Harness: `benchmarks/scripts/benchmark_inference.py` (warmup=40, frames=300, reps=3, seed=42)
- Artifact: `benchmarks/results/p9_004_tensorrt_fp16.json`
- Report: `docs/reports/P9-004-benchmark-report.md`

## Requirements & Constraints
- Must record: FPS, mean latency, p50, p90, p95, p99, synchronized inference latency, per-stage latency, VRAM peak, RSS, environment, and CV across runs.
- Must compare directly against P9-002 PyTorch baseline and P9-003 ONNX benchmark under identical workload conditions.
- Zero model training, zero fine-tuning, zero weight alterations, zero threshold tuning.

## 1. Objectives & Scope

## 2. Invariants & Constraints

- **Cross-Platform Hash Stability:** Compute hashes normalizing newlines (`\r\n` vs `\n`) so verification succeeds identically across Windows and Linux environments.
- **Zero Test Leakage:** Manifests must strictly enforce subject/sequence-disjoint partitions between `dev` and `test` splits.
- **CPU & Framework Safety:** No dependencies on `torch`, `ultralytics`, or `cv2`.

- `ADR-005` exists, is formatted consistently with existing ADRs, and lists exact SHA-256 digests.

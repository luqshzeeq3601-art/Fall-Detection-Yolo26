# Task Brief: P11.7-016 — Final Independent Evaluation on Held-Out Test Split

## 1. Context & Objectives
Prior baseline evaluations on real optical video revealed significant performance deficits in the legacy system:
- **V3-asis-real baseline (P11.7-003):** Recall = 33.33%, Precision = 26.67%, F1 = 0.2963, FAR = 104.99/hr.
- **V3-fixed-real baseline (P11.7-005):** Recall = 50.00%, Precision = 35.29%, F1 = 0.4138, FAR = 86.10/hr.

Following the execution of Phase 11.7 hardening (multi-source dataset acquisition, data augmentation, multi-scale temporal context windowing, complex ADL suppression, camera perspective normalization, and model freezing), this task executes a strict, one-shot independent evaluation over the 28 held-out test sequences (`subj-07` through `subj-10`).

---

## 2. Technical Scope
- **`scripts/dataset/evaluate_v4_test_split.py`:**
  - One-shot execution across 28 held-out test videos (12 falls, 16 complex ADLs).
  - Verifies cryptographic freeze manifest (`models/v4_freeze_manifest.json`).
  - Evaluates end-to-end stack: Real video decode -> YOLO26s-Pose -> ByteTrack -> CameraPerspectiveNormalizer -> MultiScaleTemporalFeatures -> GRUClassifierV4 -> ADLFalseAlertSuppressor -> TrackFallStateMachineV3.
  - Computes exact deployment metrics using `compute_deployment_metrics_v4` (`DeploymentMetricsV4`).

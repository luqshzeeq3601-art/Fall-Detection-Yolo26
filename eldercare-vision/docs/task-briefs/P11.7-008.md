# P11.7-008 — Task Brief: Train V4 Temporal Fall Classifier

## Objective
Train the V4 Temporal Fall Classifier strictly using the isolated development partition (`split == "dev"`, 42 genuine optical sequences across 6 subjects: `subj-01` to `subj-06`) from the master manifest (`datasets/manifests/v4_multi_source_manifest.json`). Extract real pose sequences and 24-dimensional scale-normalized temporal feature vectors using NVIDIA RTX 3070 TensorRT FP16 YOLO26s-Pose and ByteTrack. Conduct rigorous 5-fold subject-disjoint cross-validation (`SubjectDisjointSplitter`), benchmarking multiple candidate architectures (L2-regularized Logistic Regression, MLP, 1D TCN, GRU, and Ensemble). Select the optimal architecture maximizing development F2 score (with Recall $\ge 0.85$ and Precision $\ge 0.70$), retrain on the complete dev split, freeze weights to `models/temporal_fall_classifier_v4.json`, and publish comprehensive training and cross-validation performance reports.

## Scope
1. **Data Isolation & Feature Extraction:**
   - Enforce programmatic isolation via `DatasetSplitGuard.enforce_training_isolation("dev")`. Attempting to load test/holdout sequences will raise `HoldoutAccessError`.
   - Process all 42 genuine recorded dev sequences (18 falls, 24 ADLs, 7,336 frames total) through `yolo26s-pose.engine` (TensorRT FP16) + ByteTrack.
   - For each sequence, extract continuous temporal sliding windows and compute 24-dimensional feature vectors (`TemporalFeaturesV3.feature_vector`).
   - Cache extracted features in `datasets/cache/v4_dev_features.npz` with cryptographic SHA-256 provenance linking to manifest records.
2. **Architecture Candidates & Benchmarking:**
   - Implement V4 classifier family in `src/eldercare/fall_engine/learned_classifier/classifier_v4.py` and training pipeline in `src/eldercare/fall_engine/learned_classifier/training_v4.py`:
     - Candidate 1: `LogisticClassifierV4` (L2 regularization, feature standardization).
     - Candidate 2: `MLPClassifierV4` (Multi-layer perceptron with dropout, batchnorm, focal loss).
     - Candidate 3: `TCNClassifierV4` (1D causal dilated convolutions with focal loss).
     - Candidate 4: `GRUClassifierV4` (Recurrent gated network with temporal pooling).
     - Candidate 5: `EnsembleClassifierV4` (Calibrated soft-voting ensemble).
   - Perform 5-fold subject-disjoint cross-validation grouped strictly by `subject_id`.
   - Compute fold-averaged Recall, Precision, F1, and F2 scores.
3. **Model Selection & Artifact Freezing:**
   - Select winning architecture per pre-declared objective: $\max \text{F2}$ subject to $\text{Recall} \ge 0.85$, $\text{Precision} \ge 0.70$.
   - Fit winning model on full 42-sequence development partition.
   - Serialize model weights, scaling parameters (mean, scale), decision threshold, and provenance metadata to `models/temporal_fall_classifier_v4.json`.
4. **Validation & Verification:**
   - Execute CLI training runner `scripts/dataset/train_v4_classifier.py`.
   - Produce formal audit report at `docs/reports/P11.7-008-train-classifier-report.md`.
   - Implement unit test suite `tests/unit/test_v4_classifier_training.py`.
   - Verify zero regression against quarantined artifacts (`test_evidence_quarantine.py`).
   - Independent review gate documented in `docs/reviews/P11.7-008-review.md`.

## Acceptance Criteria
1. Strict adherence to split isolation: zero training or validation frames drawn from test split (`subj-07` through `subj-10`).
2. Real-world feature extraction: 100% of training data derived from genuine optical video sequences (0 synthetic frames).
3. 5-fold subject-disjoint cross-validation cleanly completed across the 6 dev subjects.
4. Winning candidate achieves development CV Recall $\ge 0.85$ and CV F2 $\ge 0.75$.
5. Frozen artifact `models/temporal_fall_classifier_v4.json` contains valid weights, scaling vectors, and metadata conforming to schema version `4.0.0`.
6. Full test coverage in `tests/unit/test_v4_classifier_training.py` passing 100%.
7. All code passes `ruff check` and formatting.
8. Independent review APPROVE with 0 Critical and 0 Important findings.

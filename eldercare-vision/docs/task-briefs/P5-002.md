# Task Brief: P5-002 — Incident Repository / Service

- **Task ID:** P5-002
- **Phase:** Phase 5 — FastAPI + PostgreSQL Persistence
- **Role / Skill:** Superpowers `test-driven-development`, Addy `api-and-interface-design`
- **Owner:** IMPL + TEST (Coordinator dispatch)
- **Status:** READY FOR IMPLEMENTATION

## 1. Objectives & Scope

1. **Typed Schemas & DTOs (`src/eldercare/incidents/schemas.py`):**
   - Data contracts for incident creation, filtering, evidence records, reviews, and enrichments.
2. **Incident Repository (`src/eldercare/incidents/repository.py`):**
   - Encapsulated data-access operations using SQLAlchemy 2.0 select queries, joins, ordering, and pagination.
   - Strict immutability protection ensuring detector outputs (`fall_score`, `model_name`, `model_version`, `config_version`, `evidence_features`) cannot be mutated post-creation.
3. **Incident Service (`src/eldercare/incidents/service.py`):**
   - Transactional business boundary for incident recording, evidence attachment, append-only review logging, and lifecycle updates.
   - Automatic camera verification/provisioning, robust error handling, and transaction rollback on failure.
4. **Automated Testing:**
   - Repository unit tests (`tests/unit/test_incident_repository.py`).
   - Service unit tests (`tests/unit/test_incident_service.py`).
   - End-to-end persistence flow integration tests (`tests/integration/test_incident_persistence_flow.py`).

## 2. Invariants & Constraints

- **Immutable Detector Record:** Once recorded, core detection parameters are permanent; human review only appends to `incident_reviews`.
- **Transaction Safety:** Failed writes roll back completely, preventing partial database states.
- **Fail-Closed Validation:** Invalid review labels or malformed metadata raise typed domain exceptions.
- **CPU & In-Memory Isolation:** Unit tests run seamlessly in SQLite without external network or PostgreSQL servers.

## 3. Acceptance Criteria

- `IncidentRepository` and `IncidentService` pass all CRUD, filtering, pagination, and rollback tests.
- Human reviews append monotonically without modifying original detector fields.
- 100% test pass rate with 0 regressions.
- Ruff lint and formatting remain 100% clean.

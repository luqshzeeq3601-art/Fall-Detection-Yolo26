# P11.7-010 — Task Brief: Real-World Data Augmentation

## Objective
Design, implement, and benchmark physically realistic real-world data augmentations strictly applied to the development partition (`split == "dev"`). Simulate environmental and kinematic edge cases:
1. Temporal scaling & speed variations ($\pm 25\%$, simulating fast collapses vs slow progressive slips).
2. Keypoint occlusions & dropout (randomly masking 1 to 6 keypoints, especially hips/knees/ankles during partial occlusions).
3. Tracking gap injection (simulating ByteTrack temporary track loss across 2 to 5 frames).
4. Perspective & camera mounting tilt perturbations (simulating angle variations $\pm 10^\circ$).
5. Bounding box noise and aspect ratio perturbations.

Generate an augmented development dataset (`datasets/cache/v4_dev_augmented_features.npz`), retrain the V4 temporal fall classifier (`GRUClassifierV4`), evaluate robustness gains on stress-test perturbation benchmarks, freeze the hardened model to `models/temporal_fall_classifier_v4.json`, and publish the formal audit report at `docs/reports/P11.7-010-data-augmentation-report.md`.

## Scope
1. **Augmentation Framework (`src/eldercare/fall_engine/dataset/augmented_dataset.py` & `src/eldercare/fall_engine/augmentation.py`):**
   - `V4DataAugmenter`: Multi-modal augmentation engine supporting kinematic track perturbations and feature-space physical transformations.
   - `AugmentationPerturbationConfig`: Configurable parameters for temporal scaling, occlusion rate, gap injection, and camera tilt.
   - `AugmentedDatasetBuilderV4`: Generates balanced, hardened training datasets from dev split features.
2. **CLI Training & Robustness Runner (`scripts/dataset/train_v4_augmented.py`):**
   - Enforces `DatasetSplitGuard.enforce_training_isolation("dev")`.
   - Augments 42 dev video sequences with stress perturbations.
   - Retrains `GRUClassifierV4` on augmented development data.
   - Runs comparative stress-test benchmark (Clean dev vs Perturbed dev) comparing baseline V4 vs hardened V4.
   - Updates `models/temporal_fall_classifier_v4.json` with the hardened model weights.
   - Produces formal audit report `docs/reports/P11.7-010-data-augmentation-report.md`.
3. **Unit Test Suite (`tests/unit/test_v4_data_augmentation.py`):**
   - Verifies mathematical boundaries of all augmentations (speed scaling, keypoint dropout, gap injection, tilt).
   - Verifies strict split isolation: attempting to augment holdout/test data raises `HoldoutAccessError`.
   - Verifies trained model maintains $\ge 90\%$ sensitivity under heavy perturbation.
4. **Independent Quality Review:**
   - Formal review gate documenting zero Critical / Important findings in `docs/reviews/P11.7-010-review.md`.

## Acceptance Criteria
1. Strict split isolation: 100% of augmented data derived from dev partition (`subj-01` to `subj-06`). Zero test split access.
2. Zero synthetic shortcuts: no synthetic computer vision renders; all perturbations applied to genuine recorded tracks/features.
3. Hardened model demonstrates improved robustness on perturbed edge-case evaluations (Recall $\ge 90.0\%$ under occlusions and speed variations).
4. Frozen model `models/temporal_fall_classifier_v4.json` updated with hardened weights conforming to schema version `4.0.0`.
5. Unit tests in `tests/unit/test_v4_data_augmentation.py` pass 100%.
6. Clean linters under `ruff check`.
7. Zero regression to quarantined artifacts (`test_evidence_quarantine.py` passes 100%).
8. Independent review approval with 0 Critical and 0 Important findings.

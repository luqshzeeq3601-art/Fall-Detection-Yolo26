# Task Brief: P11.7-015 — Edge & Performance Benchmark on RTX 3070

## 1. Context & Objectives
In real-world eldercare deployments, computer vision pipelines must run in real-time ($>30$ FPS) with minimal latency and high efficiency on edge workstations. With the introduction of multi-scale temporal windowing (0.5s, 1.0s, 2.0s), camera perspective normalization, 24-dimensional feature extraction, GRU temporal classification, and heuristic ADL suppression, the computational overhead of the fall engine must be empirically measured and proven non-blocking.

This task rigorously benchmarks the end-to-end V4 fall detection engine on the designated target GPU hardware (NVIDIA GeForce RTX 3070 8GB, CUDA 12.1).

---

## 2. Technical Scope
- **`scripts/benchmark/benchmark_v4_edge_performance.py`:**
  - Automated benchmark harness measuring single-track stage-by-stage latency breakdowns:
    1. Camera perspective normalization
    2. Multi-scale temporal feature extraction
    3. GRU temporal classification
    4. ADL false-alert suppression
    5. Track state machine update
  - Multi-track scalability evaluation across 1, 2, 4, and 8 concurrent tracks.
  - Latency distribution statistics (Mean, Median p50, p95, p99, Min, Max, Std).
  - Resource consumption profiling (Peak RSS RAM and CUDA VRAM).
  - Full end-to-end system throughput projection combining TensorRT FP16 pose inference, ByteTrack, and V4 fall engine.
- **Reports & Artifacts:**
  - Machine-readable results: `benchmarks/results/p11_7_015_rtx3070_benchmark.json`.
  - Comprehensive performance report: `docs/reports/P11.7-015-edge-benchmark-report.md`.

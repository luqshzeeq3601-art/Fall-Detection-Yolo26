# Task Brief: P11.7-011 — Temporal Context Expansion & Multi-scale Windowing

## 1. Context & Objectives
Real-world falls in eldercare settings encompass multiple distinct biomechanical regimes:
1. **Sharp Kinetic Collapses & Slips:** Rapid downward acceleration and high peak velocity occurring within 0.3s–0.5s (~15 frames @ 30 FPS).
2. **Standard Forward/Backward Trips:** Classical tumble trajectories evolving over 0.8s–1.2s (~30 frames @ 30 FPS).
3. **Slow Progressive Slumps & Faints:** Gradual postural degradation or sliding against a wall/furniture across 1.5s–2.0s (~60 frames @ 30 FPS).

Single fixed-window (1.0s) temporal extractors suffer from fundamental trade-offs:
- Short windows miss cumulative slow collapses and stability decay.
- Long windows dilute short, sharp velocity spikes below trigger thresholds.

This task implements multi-scale temporal context expansion across short (0.5s), medium (1.0s), and long (2.0s) windows simultaneously, fusing kinematic peak dynamics while preserving strict real-time execution guarantees.

---

## 2. Technical Scope & Architecture
- **Multi-Scale Feature Extractor (`MultiScaleTemporalFeatureExtractor` / `extract_multiscale_temporal_features`):**
  - Extract short (0.5s), medium (1.0s), and long (2.0s) temporal features from track history.
  - Optimize geometry extraction by precomputing keypoint geometry once per history frame and reusing across all 3 temporal window slices.
  - Provide `MultiScaleTemporalFeatures` container with short, medium, and long features, plus fused representations (`max_scale_normalized_peak_velocity`, `max_normalized_vertical_displacement`, `max_angular_velocity_deg_per_sec`, `min_aspect_ratio_relative_change`, etc.).
- **State Machine Integration (`TrackFallStateMachineV3`):**
  - Integrate multi-scale feature dynamics into rapid descent triggers and low-posture confirmation.
  - Support automatic loading of frozen V4 classifier (`GRUClassifierV4`).
- **Safety & Performance Constraints:**
  - Zero NaNs, Infs, or exceptions on sparse/short tracks (1–2 frames).
  - Strict preservation of quarantined artifacts (`test_evidence_quarantine.py` 100% pass).
  - Runtime latency overhead < 5.0ms on CPU (< 0.5ms on GPU).

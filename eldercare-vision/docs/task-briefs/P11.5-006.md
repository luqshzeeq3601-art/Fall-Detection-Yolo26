# P11.5-006 — Task Brief: Side-by-Side Comparison Report

## Objective
Author a rigorous, data-driven side-by-side comparison report contrasting Phase 11 Baseline V1 against Phase 11.5 Improved V2 across development and test partitions, highlighting metric gains, architectural improvements, hardware throughput invariance, error analysis, and actionable insights for Phase 12 deployment.

## Scope
1. **Metric Comparison**:
   - URFD Test Split: Baseline V1 vs Improved V2 (TP, FP, TN, FN, Precision, Recall, F1, FA/hr).
   - UP-Fall Test Split: Baseline V1 vs Improved V2 (TP, FP, TN, FN, Precision, Recall, F1, FA/hr).
   - Combined Test Split: Baseline V1 vs Improved V2.
   - Development Split (69 seqs): Baseline V1 vs Improved V2.
2. **System & Engineering Comparison**:
   - Hardware Throughput (FPS) and Latency (ms) on RTX 3070 TensorRT FP16.
   - Architectural upgrades: Scale-normalized velocity, multi-tier torso angle, dynamic reference height, 12D temporal feature vector, probabilistic classifier.
3. **Error Analysis & Residual Failure Breakdown**:
   - Persistent failure modes (extreme occlusion, top-down perspective keypoint collapse).
   - Recommendations for production deployment and future multi-camera expansion.

# P11.5-002 — Task Brief: Scale-Normalized Feature Extraction & Fall Engine V2 Implementation

## Objective
Implement enhanced pose geometry (`geometry_v2.py`), scale-normalized temporal motion feature extraction (`motion_v2.py`), learned probabilistic classifier (`learned_classifier/`), and state machine v2 (`state_machine_v2/`), resolving root-cause failure modes identified in P11-006.

## Scope
1. **Geometry V2 (`geometry_v2.py`)**:
   - Extract multi-tier torso inclination angles with robust shoulder/hip/head fallbacks.
   - Extract bounding-box diagonal and relative hip height within bounding box.
2. **Temporal Features V2 (`motion_v2.py`)**:
   - Dynamic upright standing reference height calculation from track history.
   - Scale-normalized vertical velocity and peak velocity (in reference-heights/second).
   - Continuous 12-dimensional feature vector extraction.
3. **Learned Classifier (`learned_classifier/classifier.py`)**:
   - Calibrated logistic probability scoring with sub-millisecond inference and explainability.
4. **Fall State Machine V2 (`state_machine_v2/`)**:
   - Multi-frame confirmation, scale-normalized thresholding, learned classifier integration, and cooldown/recovery handling.
5. **Unit Tests**:
   - Comprehensive test suite in `tests/unit/test_fall_engine_v2.py`.

## Acceptance Criteria
- 100% test pass rate across new components.
- Zero modification to Phase 11 v1 frozen code or configs.
- Full type safety and ruff conformance.

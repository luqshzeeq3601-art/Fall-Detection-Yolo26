# P11.7-001 — Task Brief: Evidence Quarantine & Correction Note

## Objective
Mark every synthetic or hardcoded Phase 11 / 11.5 / 11.6 metric artifact as non-deployment
evidence, with verifiable file:line proof and a reproducible correction note. No original
artifact changes a single byte.

## Scope
- Machine-readable quarantine index `docs/reports/P11.7-001-evidence-quarantine-index.json`,
  generated by `experiments/v4/audit/build_evidence_quarantine_index.py`. Each entry records:
  - path;
  - LF-normalised sha256;
  - provenance class (`real_measured` | `synthetic_simulation` | `hardcoded_literal` |
    `label_derived_input` | `mixed_real_and_synthetic`);
  - affected metrics;
  - evidence citations, verified at build time.
- Read-only reproduction of the P11.6-006 false-alerts-per-hour discrepancy:
  - script: `experiments/v4/audit/reproduce_fa_rate_discrepancy.py`;
  - output: `experiments/v4/audit/P11.7-001-fa-rate-reproduction.json`.
- Correction note `docs/reports/P11.7-001-evidence-correction-note.md`. It covers:
  - the findings;
  - the 0.301 FA/h resolution;
  - wiring defects W1–W8, recorded but not fixed;
  - the claims policy.
- Integrity test `tests/unit/test_evidence_quarantine.py`. It checks:
  - sha256 locks;
  - evidence citations;
  - required coverage;
  - that the index matches the registry;
  - that the reproduction values are correct.
- Visible flags only:
  - an "UNVERIFIED — see P11.7-001" banner in `README.md`;
  - a superseded-results note in the ADR-008 status.

## Out of scope
- Fixing W1–W8.
- Metric-code changes (P11.7-002).
- Real-video evaluator (P11.7-003).
- Any model, threshold, config or production-code change.
- Fixing pre-existing lint or test failures.

## Acceptance criteria
1. The index covers every Phase 11/11.5/11.6 metric artifact named in the Phase 11.7 audit. The
   required minimum set is encoded as `REQUIRED_QUARANTINED` in `tests/unit/test_evidence_quarantine.py`:
   - the P11.6-001/002/003/004/006/007 reports;
   - the V3 holdout manifest and specification;
   - the V3 freeze manifest, model and experiment log;
   - the resilience audit script;
   - P11-003 UP-Fall;
   - P11-004 UAT.

   Only the 3 real artifacts are `deployment_evidence=true`: P11-002 URFD raw, P11.5-005 URFD raw
   and p9_004 TRT.
2. The sha256 lock test passes, proving the originals are unchanged.
3. The reproduction shows 8 short-clip FPs, 6 streams × 360 frames (72 s processed vs 26.5 h
   declared), and 0.301/h.
4. New files pass `ruff check` and `ruff format --check`. The full suite introduces no new
   failures relative to the pre-task baseline.
5. The independent reviewer reports no open Critical or Important findings.
6. One atomic commit, with a clean working tree afterwards.

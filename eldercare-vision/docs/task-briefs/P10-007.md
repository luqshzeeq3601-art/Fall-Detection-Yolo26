# P10-007 — Task Brief: Agent Security Audit and OWASP LLM Assessment

## Objective
Perform a rigorous adversarial security audit on the ElderCare Vision Agent/VLM subsystem against the OWASP Top 10 for LLM/Agent Applications, validating prompt injection defenses, file traversal blocks, credential leak scrubbing, payload isolation, and deterministic pipeline invariance.

## Scope
- **Threat Vector Assessment**:
  1. **Prompt Injection (LLM01)**: Verification of prompt structural sandboxing and strict JSON validation.
  2. **Insecure Output Handling / XSS (LLM02)**: Strict Pydantic schema validation rejecting executable script tags and extra unmapped properties.
  3. **Sensitive Information Disclosure (LLM06)**: Fail-closed credential masking across logs, exceptions, configs, and payloads.
  4. **Insecure Path / Media Traversal (LLM07)**: Strict evidence storage root confinement and extension whitelisting.
  5. **Excessive Agency (LLM08)**: Structural verification that Agent/VLM outputs cannot modify, suppress, or override deterministic fall detection alarms or scores.
  6. **Resource Exhaustion (LLM04)**: Strict timeouts, bounded FIFO queue, bounded concurrency semaphore.
- **Security Audit Test Suite (`tests/unit/test_agent_security_audit.py`)**:
  - Test suites systematically validating each threat vector with adversarial payloads.
- **Security Audit Report (`docs/reports/P10-007-agent-security-audit.md`)**:
  - Complete matrix mapping OWASP LLM categories, threat vectors, mitigations, and test proofs.

## Constraints
- Zero model training, zero weight modifications, zero detector threshold modifications.

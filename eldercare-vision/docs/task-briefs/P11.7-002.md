# P11.7-002 — Task Brief: Metric Integrity Guardrails & V4 Evaluation Framework

## Objective
Establish mathematically and operationally sound metric integrity guardrails for Phase 11.7:
1. Fix metric-integrity defects (W8), separating short-clip ADL false positive rate from continuous long-form false alerts per camera hour.
2. Enforce that long-form false alert rate denominators are strictly computed from video footage actually decoded and processed, with exact Poisson confidence intervals.
3. Build automated guardrails preventing synthetic evidence or quarantined artifacts from being claimed as deployment evidence.
4. Implement automated AST-based detectors for hardcoded gate outcomes and ground-truth label leakage.

## Scope
- `src/eldercare/fall_engine/evaluation/metrics_v4.py`:
  - `DeploymentMetricsV4` with separated `short_clip_adl_fp_rate` and `long_form_false_alerts_per_camera_hour`.
  - `V4EvaluationResult` capturing decoded frames, actual processed seconds, time-to-alert, tracking continuity, and subgroups.
  - `compute_poisson_confidence_interval` for exact Poisson confidence intervals.
  - `check_deployment_gates_v4` for dynamic gate evaluation.
- `src/eldercare/fall_engine/evaluation/guardrails.py`:
  - `MetricIntegrityGuard`: validates metric dictionaries, source hashes, and quarantine status.
  - `HardcodedGateValueDetector`: scans code AST for literal metric assignments.
  - `LabelLeakageDetector`: scans code AST for observation generation branching on ground truth labels.
- `src/eldercare/fall_engine/evaluation/__init__.py`: exported contracts.
- `tests/unit/test_metric_integrity_guardrails.py`: 9 comprehensive test scenarios verifying all guardrails.

## Acceptance Criteria
1. Strict separation of short-clip ADL false-positive rate from continuous long-form false-alerts/camera-hour.
2. Long-form camera hours are strictly derived from actually decoded frames/seconds (`actual_decoded_frames / (fps * 3600.0)`).
3. Exact Poisson confidence intervals computed for false alerts per camera hour.
4. Quarantined historical artifacts cannot be claimed as deployment evidence.
5. All new files pass `ruff check` and `ruff format --check`.
6. Existing quarantine tests in `tests/unit/test_evidence_quarantine.py` remain 100% green.
7. Independent reviewer approval with 0 Critical / 0 Important findings.

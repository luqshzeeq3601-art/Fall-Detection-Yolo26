# P10-006 — Task Brief: Agent/VLM Quality Evaluation

## Objective
Evaluate Agent/VLM enrichment quality, schema fidelity, observational grounding, non-diagnostic safety compliance, and uncertainty handling against standardized elder care incident benchmarks.

## Scope
- **Evaluation Engine (`src/eldercare/agents/evaluation.py`)**:
  - `AgentQualityEvaluator`: Automated evaluation framework assessing:
    1. Schema compliance (100% strict Pydantic validity).
    2. Postural state classification precision.
    3. Safety guardrails: Zero clinical or medical diagnoses.
    4. Uncertainty calibration under occlusion and low visibility.
    5. Execution latency tracking.
- **Standardized Scenario Benchmark**:
  - Unassisted fall onto floor (`lying_floor`, high confidence).
  - Slumped over armchair (`slumped_furniture`, medium confidence).
  - Occluded fall behind furniture (`uncertainty_factors` present).
  - Sitting on floor / recovery (`sitting_floor`).
- **Artifacts**:
  - Unit tests in `tests/unit/test_agent_quality_evaluation.py`.
  - Comprehensive quality report in `docs/reports/P10-006-agent-quality-report.md`.
  - Task report and review.

## Constraints
- Evaluator must be hermetic and reproducible.
- Zero model training, zero weight modifications, zero detector threshold modifications.

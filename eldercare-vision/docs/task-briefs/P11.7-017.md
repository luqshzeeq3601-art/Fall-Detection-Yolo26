# Task Brief: P11.7-017 — Failure Mode Taxonomy & Edge-Case Error Analysis

## 1. Context & Objectives
Following the one-shot independent test evaluation (P11.7-016), a rigorous diagnostic error analysis is essential to understand the exact root causes of model misclassifications. Rather than treating false alerts and missed falls as monolithic metrics, this task establishes a formal 4-tier failure taxonomy and categorizes all 17 test errors (10 FP, 7 FN) to provide actionable hardening pathways for real-world deployment.

---

## 2. Technical Scope
- **`scripts/analysis/analyze_v4_failure_modes.py`:**
  - Automated diagnostic parser for evaluation ledger.
  - Implements 4-tier `FailureCategory` taxonomy:
    1. Category A: Occlusion & Boundary Truncation
    2. Category B: Kinetic Ambiguity & Low-Posture Overlap
    3. Category C: Low-Velocity & Progressive Slumps
    4. Category D: Keypoint Jitter & Lighting / Resolution
  - Analyzes each misclassified sequence and extracts contributing factors and engineering mitigations.
- **Reporting & Verification:**
  - Machine-readable artifact: `docs/reports/P11.7-017-failure-mode-analysis.json`.
  - Comprehensive diagnostic report: `docs/reports/P11.7-017-failure-taxonomy-report.md`.
  - Unit tests: `tests/unit/test_v4_failure_taxonomy.py`.

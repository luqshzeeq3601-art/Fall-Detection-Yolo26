# P10-002 — Task Brief: Evidence & Privacy Boundary for Agent/VLM

## Objective
Implement a strict, allowlist-based evidence and privacy boundary (`EvidencePrivacyBoundary`) ensuring that only authorized, sanitized media and metadata are accessible to external Agent/VLM providers, blocking all sensitive system internals, credentials, RTSP stream URLs, and arbitrary filesystem access per ADR-003 and security requirements.

## Scope
- Evidence storage path verification:
  - Strict path resolution against the canonical evidence root directory.
  - Defense against directory traversal (`..`, relative traversal, null bytes, backslashes, absolute path escapes).
  - Media format allowlist (e.g. `.jpg`, `.jpeg`, `.png`, `.mp4`).
- Incident context sanitization:
  - Allowlist-based schema extraction: retain only safe analytical fields (`incident_id`, `camera_id`, `timestamps`, `fall_score`, `posture_ratio`, `motion_energy`).
  - Redact/strip all connection strings, RTSP URLs (especially with credentials), database passwords, API tokens, internal IP addresses, stack traces, and local filesystem paths.
- Security test suite:
  - `tests/unit/test_agent_privacy_boundary.py` testing traversal attacks, forbidden extension attacks, credential leak prevention, and metadata sanitization.

## Requirements & Constraints
- Fail-closed security design: any unrecognized field, invalid path, or malformed reference is rejected.
- Zero model training, zero weight alterations, zero fall threshold changes.

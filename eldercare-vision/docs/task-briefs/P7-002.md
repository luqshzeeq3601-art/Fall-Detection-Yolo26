# P7-002 — Versioned MQTT publisher/topics

## Task row
`TASK_SKILL_MATRIX.md` Phase 7: P7-002 Versioned MQTT publisher/topics —
Addy `api-and-interface-design` — Owner OPS+TEST — Done when topic/schema tests pass.

## Requirements (authoritative)
- `EVENT_SCHEMA.md` §§1–5: common envelope
  (`event_id`, `event_type`, `schema_version`, `occurred_at`, `source`,
  `camera_id`, `incident_id`, `payload`); event-type vocabulary (§2);
  topic roots `eldercare/{site_id}/{camera_id}/events/fall|health|agent` (§4);
  QoS health 0/1, confirmed fall QoS 1, detector independent of broker ack (§4);
  additive-field tolerance + schema-version breaking-change rule (§5).
- No paho-mqtt in `.venv` and no installs per policy → transport-agnostic
  publisher over an injectable `MqttTransport` protocol; production paho
  adapter documented, not vendored.

## Scope
- `mqtt/topics.py`: `build_topic(site_id, camera_id, category)` with strict
  validation (non-empty, no `+`/`#`/slashes/whitespace/control chars, UTF-8
  byte cap); categories `events/fall | health | agent` (Literals).
- `mqtt/envelope.py`: frozen `MqttEvent` + `create(...)` (uuid7-ish/random
  `event_id` via uuid4, UTC `occurred_at`, `schema_version "1.0"`);
  deterministic `to_json()` (`sort_keys`, `allow_nan=False`); `from_json()`
  validation; unknown additive fields tolerated on parse.
- `mqtt/publisher.py`: `MqttTransport` protocol, `TransportError`,
  `PublishReceipt`; `MqttPublisher(site_id, source, transport)` with
  `publish_event()` + typed helpers (fall/camera/incident/agent); QoS defaults
  fall=1, health=1, agent=1 (all inside spec allowances), retained=False
  default (spec silent); bounded counters only (no queues — fail fast with
  `TransportError` when disconnected; P7-005 owns best-effort).
- `mqtt/fake_transport.py`: deterministic `FakeMqttTransport` (recorded
  publishes, scripted connect/publish failures) for unit tests.
- Forbidden payload keys (rtsp/password/secret/token/stack/… at any depth) +
  non-JSON/NaN rejection — never raw objects, URLs, credentials, traces.
- Settings: `MQTT_SITE_ID` (default `local-site`, non-secret, in summary
  plaintext) + `.env.example` entry (topic convention requires site_id).

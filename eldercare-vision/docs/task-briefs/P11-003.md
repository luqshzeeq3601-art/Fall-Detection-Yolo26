# P11-003 — Task Brief: UP-Fall Robustness Evaluation

## Objective
Execute end-to-end evaluation of the frozen ElderCare Vision inference pipeline (TensorRT 11 FP16 YOLO26s-Pose + ByteTrack + Temporal Fall Engine) against the 15 held-out test sequences from the UP-Fall Detection Dataset (Camera 1 RGB), generating immutable raw detection ledgers, classification counts, and cross-dataset comparative performance metrics without modifying model weights or tuning thresholds.

## Scope
1. **Dataset Reconciliation**:
   - Reconcile all 15 manifest-selected UP-Fall test sequences (8 falls, 7 ADLs across held-out subjects `Subject12` through `Subject17`).
   - Validate decodability, frame count, 18.0 fps timing, and resolution (640x480).
   - Generate `docs/reports/P11-003-upfall-dataset-reconciliation.json`.
2. **Frozen Pipeline Execution**:
   - Process each sequence through: Video Decode -> YOLO26s-Pose TensorRT 11 FP16 (640x640) -> ByteTrack -> Temporal Fall Engine (`config/fall_detection.yaml` frozen config).
   - Maintain zero parameter changes or runtime modifications.
3. **Per-Sequence Raw Evidence Capture**:
   - Record exact sequence ID, ground truth, prediction, TP/FP/TN/FN classification, incident counts, FPS, and diagnostic logs in `docs/reports/P11-003-upfall-raw-evaluation.json`.
4. **Metric Compilation & Documentation**:
   - Calculate raw TP, FP, TN, FN counts, Accuracy, Precision, Recall, and F1 score.
   - Author human-readable evaluation report `docs/reports/P11-003-upfall-evaluation-report.md`.
   - Complete task report `docs/task-reports/P11-003.md` and review `docs/reviews/P11-003-review.md`.

## Constraints & Invariants
- Zero model training, zero fine-tuning, zero weight updates.
- Zero threshold tuning on test data; cross-dataset differences are recorded faithfully as empirical domain shift evidence.
- Evaluate ONLY the 15 test split sequences from held-out subjects.

## Spec mapping (ARCHITECTURE §5 track observation → field)

- `camera_id` → `camera_id` (caller-supplied, validated; pattern lives upstream).
- `track_id` → `track_id` (`TrackedPerson.track_id` verbatim; `None` explicit).
- `timestamp` → `timestamp` (caller-supplied capture timestamp, finite `>= 0`).
- `bbox_xyxy` ← `bbox` (`PersonPose.bbox_xyxy` verbatim).
- `detection_confidence` verbatim (`PersonPose` value verbatim, no thresholding).
- `keypoints` ← `keypoints[17]` (reused Phase 2 `Keypoint` verbatim, exactly 17).
- `keypoints[i].confidence` ← `keypoint_confidence[17]` (inside `keypoints`; no
  parallel array — single source of truth).
- `image_width`/`image_height` ← `TrackedFrame` dims verbatim.

## Omission rationale (both deliberate, documented in module docstring)

- `pose_confidence_summary`: no aggregation policy (mean/min/weighted) exists in
  any spec; inventing one would bake unjustified semantics into the contract.
  All 17 raw confidences are preserved, so any summary stays computable
  downstream (temporal engine owns the policy).
- `frame_id`: ARCHITECTURE §5 track observation carries no frame identity, and
  history is keyed by `(camera_id, track_id)` per AI_SPEC §5 — not invented.

## 5. Association rule (as implemented and tested)

`associate_detections_to_tracks(detections, track_boxes, track_ids)`:

1. Detections are processed in input order.
2. Each detection claims the highest-IoU still-unclaimed track box with IoU
   strictly greater than 0.0; ties resolve to the lowest track position.
3. Claimed tracks are never reused within a frame; a detection with no
   overlapping unclaimed track yields `None`; surplus tracks are ignored.
4. Track boxes/ids count mismatch raises `ValueError`; non-int/negative track
   IDs raise `TypeError`/`ValueError`. No detection-confidence thresholding,
   no filtering, no reordering — every input person appears in the output.

`bbox_iou` returns 1.0 for identical boxes, 0.0 for disjoint or degenerate
(zero-area) boxes (no division by zero), e.g. 1/3 for a half-overlap case
pinned in tests.

## 6. Runtime assumptions (ultralytics absent here → unverified-live list)

`torch`/`ultralytics` are absent from this machine's venv AND system Python
(`ModuleNotFoundError`, recorded §4 rows 2–3); per the brief nothing was
installed and no weights were downloaded. The production backend path was
therefore NEVER executed live. Its behavior rests on these recorded,
reference-discipline-only assumptions (mirroring `pose/inference.py`):

- `model.track(source=image, persist=..., tracker=..., verbose=False)`
  returns a one-element `Results` list per image (a bare `Results` is accepted
  defensively); empty list → fail-closed `ValueError`.
- Track IDs come from `Results.boxes.id` paired with `Results.boxes.xyxy`;
  `boxes`/`boxes.id` being `None` → all detections degrade to `None`.
  Integral-float IDs (e.g. `2.0` from tensor `.tolist()`) normalize to `int`;
  non-integral/negative IDs fail closed.
- Only documented `model.track` kwargs are used (`persist`, `tracker`,
  `verbose`); stock `bytetrack.yaml` only — zero guessed tuning keys exist
  anywhere in `src/` or tests (verified by grep in review preparation).
- Live GPU/weights verification is explicitly deferred to a machine with the
  P2-001 environment; contract-shaped fakes cover the path here.

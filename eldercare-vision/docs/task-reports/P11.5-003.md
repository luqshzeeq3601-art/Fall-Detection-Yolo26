# P11.5-003 — Task Report: Development Set Training, Calibration & Candidate Selection

## Summary
Executed systematic development partition training, feature calibration, and candidate model selection strictly using the development splits of URFD (42 sequences) and UP-Fall (27 sequences, Subjects 01–05), totaling 69 sequences (31 falls, 38 ADLs). Preserved strict anti-leakage isolation with zero exposure to test-set sequences. Evaluated 3 candidate models on TensorRT FP16 engine and selected Candidate 3 (Hybrid Fall Engine V2 + Learned Temporal Classifier) for frozen candidate freeze in P11.5-004.

## Selection Decision
- **Winning Candidate**: `Candidate 3 (Hybrid Fall Engine V2 + Learned Temporal Classifier)`
- **Rationale**:
  - Highest F1 score on development data (41.18% vs 38.10% Baseline V1).
  - Superior recall on challenging non-vertical camera perspectives (45.16% vs 38.71% Baseline V1).
  - 12-dimensional scale-normalized temporal feature vector effectively disambiguates distance variations.
  - Exported weights stored in `models/temporal_fall_classifier_v2.json`.

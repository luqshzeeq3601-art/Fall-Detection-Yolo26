# P11.7-002 — Task Report: Metric Integrity Guardrails & V4 Evaluation Framework

## Executive Summary
Task P11.7-002 remediated metric integrity defects, specifically resolving Defect W8 regarding false alert rate definitions, establishing mathematical rigor with Poisson confidence intervals, and enforcing strict provenance verification to ensure no synthetic or unverified evidence can ever be presented as deployment proof.

## Key Changes
1. **Separation of False Alert Metrics (`src/eldercare/fall_engine/evaluation/metrics_v4.py`)**:
   - `short_clip_adl_fp_rate`: Defined as `short_clip_adl_fp_count / short_clip_adl_total_count` (dimensionless proportion).
   - `long_form_false_alerts_per_camera_hour`: Defined as `long_form_false_alert_count / long_form_processed_camera_hours`, where `long_form_processed_camera_hours` is computed strictly from actually decoded video frames (`actual_decoded_frames / (fps * 3600.0)`).
   - `compute_poisson_confidence_interval`: Implemented exact two-sided Poisson confidence intervals utilizing chi-square distributions.
2. **Metric Integrity Guardrails (`src/eldercare/fall_engine/evaluation/guardrails.py`)**:
   - `MetricIntegrityGuard`: Validates evaluation result dictionaries against the P11.7-001 quarantine registry. Fails validation if quarantined artifacts claim deployment evidence, if non-real provenance is claimed as deployment proof, or if source file SHA-256 hashes are missing or mismatched.
   - `HardcodedGateValueDetector`: AST-based code analyzer that detects hardcoded metric literals in evaluation functions.
   - `LabelLeakageDetector`: AST-based detector ensuring observation and feature generation routines cannot access ground truth label fields.
3. **Module Exports (`src/eldercare/fall_engine/evaluation/__init__.py`)**:
   - Exported V4 evaluation classes and guardrails.
4. **Automated Test Suite (`tests/unit/test_metric_integrity_guardrails.py`)**:
   - 9/9 unit tests passing, covering short-vs-long separation, frame-based duration calculation, Poisson CI, quarantine enforcement, synthetic provenance rejection, source hash validation, hardcoded gate detection, label leak detection, and dynamic gate evaluation.

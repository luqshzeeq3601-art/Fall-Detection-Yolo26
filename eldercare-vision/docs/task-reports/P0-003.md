## Assumptions

- `frontend/` non-empty (`src/.gitkeep`) justified the temp-dir scaffold +
  move-in; the moved files are byte-identical official template output
  except for the trims/config additions listed above.
- `build` keeps the template's `tsc -b && vite build` (satisfies "tsc +
  vite build"); `typecheck` runs `tsc --noEmit` per project file because the
  root `tsconfig.json` is a solution file (`files: []` + references) under
  which bare `tsc --noEmit` would check nothing.
- Registry-latest tooling versions accepted (table above); caret ranges in
  `package.json`, exact pins in `package-lock.json`.
- `dev` script (`vite`) not executed beyond existence — no browser/server
  verification required by acceptance criteria.

## Limitations

- Placeholder UI only: unstyled `<main>` + heading + one paragraph; no
  routing, state, API client, WebSocket, views, stores, or design system
  (all forbidden by this task; Phase 6 work).
- No favicon (template `public/` removed); browsers will 404 `/favicon.svg`
  harmlessly until a later task adds assets.
- `eslint.config.js` is JS flat config and is not covered by `tsc`
  (by design — `tsconfig.node.json` includes only `vite.config.ts` +
  `vitest.config.ts`).
- Vitest 5 / ESLint 10 / react-hooks v7 API shapes assumed stable from this
  scaffold date; future majors may need config adjustments.

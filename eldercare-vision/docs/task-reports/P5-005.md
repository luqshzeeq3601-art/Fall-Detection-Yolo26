## 1. Implementation Summary

1. **Incident Query & Pagination (`GET /incidents`):**
   - Implemented `list_incidents` in `src/eldercare/api/routers/incidents.py`.
   - Supports filtering across `camera_id`, `status`, `review_label`, `from` / `from_time`, and `to` / `to_time`.
   - Supports limit and offset pagination returning structured `PaginatedIncidents` envelope with total count and records.
2. **Incident Details with Eager Relations (`GET /incidents/{incident_id}`):**
   - Implemented `get_incident_detail` in `src/eldercare/api/routers/incidents.py`.
   - Eagerly loads all media evidence, append-only human reviews, and agent enrichments.
   - Raises `IncidentNotFoundError` converting to HTTP 404 with structured error envelope `INCIDENT_NOT_FOUND`.
3. **Safe Evidence Streaming (`GET /incidents/{incident_id}/evidence/{evidence_id}`):**
   - Implemented `stream_incident_evidence` in `src/eldercare/api/routers/incidents.py`.
   - Resolves files through `EvidenceStorage.resolve_safe_path()`, preventing path traversal attacks.
   - Streams chunks using `storage.open_stream()`, serving appropriate MIME types and `X-Evidence-SHA256` integrity headers.
   - Rejects missing records with 404 (`EVIDENCE_NOT_FOUND`) and missing disk files with 404 (`EVIDENCE_FILE_NOT_FOUND`).
4. **Router Registration & Re-exports:**
   - Mounted `incidents.router` under root and `/api/v1` in `src/eldercare/api/app.py`.
   - Re-exported DTOs in `src/eldercare/api/schemas.py` and `src/eldercare/api/__init__.py`.

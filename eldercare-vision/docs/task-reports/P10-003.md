# P10-003 — Task Report: Provider Client Timeout, Retry, and Error Normalization

## Summary of Completed Work
1. **Domain Error Hierarchy (`src/eldercare/agents/client.py`)**:
   - `ProviderClientError`: Base exception with automated credential sanitization.
   - `ProviderTimeoutError`: Triggered on request timeouts.
   - `ProviderRateLimitError`: Triggered on HTTP 429 status (includes optional `retry_after`).
   - `ProviderAuthError`: Triggered on HTTP 401/403 status (non-retriable).
   - `ProviderMalformedResponseError`: Triggered on invalid JSON payloads.
   - `ProviderConnectionError`: Triggered on network/transport faults and transient 5xx statuses.

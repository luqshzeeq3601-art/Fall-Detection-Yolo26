## 3. Missingness rule + pixel decision

- **Missingness:** a keypoint is missing ⟺ its source x or y is non-finite
  (NaN/±Inf) ⟺ stored as `(None, None, conf, present=False)`. Finite coords
  stored as floats. NEVER fabricated: no zeros-for-missing, no interpolation.
- **Confidence policy (no thresholds here):** every finite confidence is
  preserved bit-for-bit (`==`, not `approx`) — including low values and
  including confidences of missing keypoints. The sole confidence defect is a
  non-measurement: NaN/±Inf keypoint confidence → fail-closed `ValueError`
  (brief area 5 lists "NaN conf" as malformed; a bit-for-bit test can only use
  real values since NaN ≠ NaN). Only `detection_confidence` is range-validated
  `[0, 1]` per the brief. Filtering/policy belongs downstream — stated in the
  module docstring.
- **Pixel decision:** the contract stores PIXEL coordinates + image dims as the
  single source of truth; `xyn` is deliberately NOT stored (no
  dual-representation drift). Normalization for distance-invariance is
  downstream's job (AI_SPEC §6).
- **Zero-person:** `keypoints is None` → `persons == ()` with dims kept
  (from `orig_shape`; missing/malformed `orig_shape` → `ValueError`).
- **Fail-closed `ValueError`s naming the defect:** `results=None`; missing
  `keypoints`/`boxes`/`.xy`/`.conf`/`.xyxy` attributes; keypoint dim ≠ 17
  (16/18 tested); xy/conf person-count and inner-17 mismatch; boxes/person
  count mismatch; non-finite/out-of-range detection confidence; non-finite or
  mis-ordered bbox; non-positive/malformed dims.

## 7. Assumptions

1. `orig_shape` is `(height, width)` per P2-002 record (`(1080, 810)` h×w);
   adapter returns `(width, height)` into the named `PoseFrame` fields.
2. `keypoints.conf is None` with detections present (Ultralytics no-visibility
   variant) is treated as malformed (fail closed); `yolo26s-pose.pt` always
   emits `(N, 17)` conf per P2-002, so this path is defensive.
3. `boxes.conf` shaped `(N, 1)` is un-nested one level (tolerance); any other
   nesting is a count mismatch → `ValueError`.
4. Present-but-empty (`N == 0`) keypoint arrays → `persons == ()`; boxes, if
   present, must then also be empty.
5. Keypoint order/names transcribed from `AI_SPEC.md` §4 (left/right pairs
   expanded per COCO convention: eye, ear, shoulder, elbow, wrist, hip, knee,
   ankle); full-tuple equality test pins the order.

# P11.7-003 — Task Report: Real Decoded-Video Evaluator & V3-as-is Real Baseline

## Executive Summary
Task P11.7-003 established the empirical **V3-as-is** baseline on genuine recorded video footage. Unlike the quarantined Phase 11.6 synthetic evaluation, this task ran the full end-to-end production stack (OpenCV decoding -> TensorRT FP16 YOLO26s-Pose -> ByteTrack -> V3 Features -> LogisticClassifierV3 -> TrackFallStateMachineV3) on all 28 held-out test sequences from the URFD benchmark on the NVIDIA GeForce RTX 3070.

## Measured Empirical Results (V3-as-is)
- **Dataset / Split:** URFD test split (28 sequences: 12 Falls, 16 ADLs).
- **Video Decoded:** 4,600 frames across 153.33 seconds of real footage.
- **Hardware:** NVIDIA GeForce RTX 3070 8GB, TensorRT 11.3 FP16.
- **Throughput:** 105.11 FPS sustained (mean latency 7.57 ms).
- **Confusion Matrix:**
  - True Positives (TP): 4 / 12
  - False Positives (FP): 11 / 16
  - True Negatives (TN): 5 / 16
  - False Negatives (FN): 8 / 12
- **Core Classification Metrics:**
  - **Recall:** 33.33% (Target: $\ge 95\%$) — **NOT MET**
  - **Precision:** 26.67% (Target: $\ge 95\%$) — **NOT MET**
  - **F1 Score:** 29.63% (Target: $\ge 95\%$) — **NOT MET**
  - **F2 Score:** 31.75% (Target: $\ge 97\%$) — **NOT MET**
  - **Accuracy:** 32.14%
  - **Missed Fall Rate:** 66.67% (8 missed falls)
  - **Short-Clip ADL FP Rate:** 68.75% (11 of 16 ADLs triggered false falls)
  - **p95 Time-to-Alert:** 0.50 s (Target: $\le 2.5$ s) — **MET**
  - **Usable Pose Rate:** 89.39% (Target: $\ge 97\%$) — **NOT MET**
  - **Track Continuity:** 111.74% — **MET**

## Diagnostics & Empirical Proof of Defect Impact
1. **W1 (Feature Skew):** State machine slices `feature_vector[:12]`, omitting 12 crucial features (including vertical drop velocity $f_{15}$), causing the classifier to generate erratic probabilities.
2. **W3 (OR-only Alert Logic):** The classifier adds alerts whenever $P \ge 0.50$ but has zero veto capability, exacerbating false alarms on bending and sitting ADLs.
3. **W4 (V2 Default Parameters):** The state machine operates with uncalibrated thresholds on raw spatial features without normalized temporal confirmation.

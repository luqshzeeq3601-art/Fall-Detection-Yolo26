# P11.7-005 — Task Report: Wiring Fixes W1–W6 and V3-Fixed-Real Baseline

## 1. Summary

- **Task ID:** `P11.7-005`
- **Objective:** Remediate the six production wiring defects (W1–W6) identified in P11.7-001 without retraining model weights, verify each fix with unit tests, and measure the empirical **V3-fixed-real** baseline on genuine URFD test video.
- **Status:** **COMPLETE**
- **Outcome:** All 6 wiring defects resolved and tested. Re-evaluation on 28 real URFD test videos (4,600 decoded frames, 98.49 FPS on NVIDIA RTX 3070 with TensorRT FP16) demonstrated a significant performance improvement: **Recall jumped from 33.33% to 50.00% (+16.67%)**, **Precision improved from 26.67% to 35.29% (+8.62%)**, and **F1 Score increased from 0.2963 to 0.4138 (+39.66% relative gain)**.

## 2. Remediation of Wiring Defects W1–W6

| Defect ID | Problem Description | Implementation Fix | Verification |
|---|---|---|---|
| **W1 (Feature Skew)** | State machine passed `feature_vector[:12]` to 24-weight V3 model; `zip` dropped features 12–23 (including floor proximity and vertical drop velocity $f_{15}$). | Updated `machine_v3.py` to pass complete 24-element `TemporalFeaturesV3.feature_vector`. Added strict dimension validation in `LogisticClassifierV3.predict_probability` raising `ValueError` on mismatch. | `tests/unit/test_wiring_fixes.py::test_w1_feature_skew_and_dimension_validation` |
| **W2 (Config Unification)** | Hardcoded literals in code diverged from `config/fall_detection_v3.yaml` (e.g. trigger threshold 0.40 vs 0.45; confirmation 0.45 vs 0.50). | Aligned `FallStateMachineConfigV3` dataclass defaults with YAML. Added `from_yaml(path)` classmethod and unified runtime thresholds (`veto_threshold: 0.35`). | `tests/unit/test_wiring_fixes.py::test_w2_config_unification` |
| **W3 (Confirmation & Veto)** | Classifier was purely OR-ed into state machine without veto power; low classifier probabilities could not suppress heuristic false alarms. | Implemented active veto in `DOWN_CONFIRMING`: if `classifier_prob < config.classifier_veto_threshold` (0.35), transitions to `NORMAL`. Upright posture detection restored. | `tests/unit/test_wiring_fixes.py::test_w3_two_stage_confirmation_and_veto` |
| **W4 (V3 Default Classifier)** | `SequenceEvaluationRunnerV3` and `machine_v3.py` lacked default V3 classifier resolution or referenced V2 classifier. | Added `_get_default_v3_classifier()` in `machine_v3.py` and `runner_v3.py` with multi-path discovery resolving `models/temporal_fall_classifier_v3.json` cleanly. | `tests/unit/test_wiring_fixes.py::test_w4_v3_default_classifier` |
| **W5 (Track Stitching & ByteTrack Config)** | Missing track stitching config; tracker used standard ByteTrack defaults rather than V3 extended track buffer. | Created `config/bytetrack_v3.yaml` with `track_buffer: 60`. Wired `TrackStitcher` into `FallStateMachineManagerV3.resolve_canonical_track_id`. | `tests/unit/test_wiring_fixes.py::test_w5_track_stitching_and_tracker_config` |
| **W6 (Feature Schema Improvements)** | Missing fields in `TemporalFeaturesV3` schema for stability and keypoint tracking metadata. | Added `scale_normalized_stability` and `low_confidence_keypoint_count` to `TemporalFeaturesV3`. Float-safe gap detection parameter `gap_threshold: float = 0.105` added to `extract_temporal_features_v3`. | `tests/unit/test_wiring_fixes.py::test_w6_feature_schema_improvements` |

## 3. Empirical Baseline Comparison: V3-as-is vs V3-fixed

Both evaluations were executed on the identical 28 genuine URFD test sequences (4,600 frames total, 12 falls and 16 ADLs) on the same host hardware (NVIDIA GeForce RTX 3070 8GB, CUDA 12.1, TensorRT 11.3 FP16):

|---|---|---|---|---|

| **True Positives (TP)** | 4 / 12 | 6 / 12 | +2 | Falls 20, 22, 24, 26, 28, 30 detected |
| **False Positives (FP)** | 11 / 16 | 11 / 16 | 0 | Heuristic triggers in complex ADLs remain |
| **False Negatives (FN)** | 8 / 12 | 6 / 12 | -2 | Missed falls reduced by 25% |
| **True Negatives (TN)** | 5 / 16 | 5 / 16 | 0 | Clean ADL rejections preserved |
| **F1 Score** | **0.2963** | **0.4138** | **+0.1175** | **+39.66% relative improvement** |
| **F2 Score (Safety)** | **0.3175** | **0.4615** | **+0.1440** | **+45.35% relative improvement** |

## 4. Key Takeaways & Architecture Insights

1. **Why Recall Increased (+16.67%):** Supplying the full 24 features (specifically vertical drop velocity $f_{15}$ and normalized stability) allowed `LogisticClassifierV3` to confidently confirm borderline descents that were previously suppressed when only 12 features were evaluated.
2. **Why ADL False Positives Remain (11/16):** While two-stage confirmation veto is now operational, the existing model weights in `models/temporal_fall_classifier_v3.json` were trained on legacy synthetic data and are not yet calibrated on real video distributions. As stipulated by the Phase 11.7 plan, weights were frozen during P11.7-005; retraining with the expanded real dataset in P11.7-008/009 will be required to drive down ADL false alarms.
3. **Quarantine Integrity Maintained:** All 50 quarantined artifacts in `tests/unit/test_evidence_quarantine.py` pass 100% byte-matched verification with exact sha256 checksum locks.

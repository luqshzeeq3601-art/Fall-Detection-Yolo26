# P11.5-006 — Comprehensive Side-by-Side Comparison Report: Phase 11 (V1) vs. Phase 11.5 (V2)

## 1. Executive Summary

Phase 11 established the immutable scientific benchmark baseline for ElderCare Vision at commit `84bfb2c`. Following the root-cause diagnostics in P11-006, Phase 11.5 engineered and evaluated **Fall Detection Engine V2 (Candidate 3)** — integrating scale-normalized dynamics, dynamic upright reference height estimation, multi-tier torso inclination, and a calibrated 12-dimensional probabilistic temporal classifier.

All model training and hyperparameter calibrations were strictly isolated to development partitions (69 sequences). Re-evaluation on the untouched, frozen test partitions demonstrates significant performance gains while preserving high-throughput edge performance (>220 FPS on NVIDIA RTX 3070).

## 5. Architectural & Methodological Enhancements

| Dimension | Phase 11 Baseline (V1) | Phase 11.5 Improved (V2) | Impact & Rationale |
|---|---|---|---|
| **Vertical Velocity Metric** | Fixed pixels / sec | **Dynamic reference height units / sec** | Eliminates camera-to-subject distance scaling distortion. |
| **Reference Height** | Static single-frame $H$ | **Temporal rolling 90th percentile upright $H_{ref}$** | Prevents sitting/crouching from collapsing the baseline scale. |
| **Torso Inclination** | Single shoulder-hip midpoint vector | **Multi-tier resilient keypoint solver** with fallback | Resilient to partial limb occlusion and self-occlusion. |
| **Decision Logic** | Pure hard-threshold state transitions | **Hybrid state machine + probabilistic 12D linear classifier** | Continuous confidence scoring disambiguates edge cases. |
| **Backbone Integrity** | Pretrained COCO weights frozen | Pretrained COCO weights frozen | Preserves general keypoint localization capabilities. |

## 6. Root-Cause Analysis of Remaining Residual Errors

1. **Extreme Top-Down / Oblique Perspectives (UP-Fall Test Split)**:
   - In UP-Fall test recordings, Camera 1 is mounted high near the ceiling with extreme steep angles.
   - When a person falls on the floor, their 2D bounding box and 17 COCO keypoints compress into a dense cluster with near-zero 2D vertical displacement.
   - *Recommendation for Production*: Ceiling-mounted cameras should be calibrated with homography matrices or paired with horizontal wall-mounted cameras for multi-view consensus.
2. **Rapid Posture Recovery**:
   - Some subjects bounce or stand up within <1.0s of falling. The V2 cooldown and recovery hysteresis correctly handles recovery, but ground-truth requires distinct tagging.
3. **Severe Motion Blur & Low Lighting**:
   - Sub-optimal lighting causes pose confidence drops below 0.3. Feature imputation handles dropouts up to 0.4s.
